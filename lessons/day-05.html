DAY 5 · LEVEL 1: PYTHON

Testing with pytest and a fake LLM client

50-60 minhands-onfree
Today you will be able to write a pytest test that checks an AI function without calling the real model.

1 · Warm-up 3 min

Answer from memory, then open the answers.

  1. Why is except Exception: pass a bad idea?
  2. What does uv run do that plain python3 does not?
Answers
  1. It hides the real problem, so you get a confusing error later, or no error at all.
  2. It uses the project’s private toolbox, so your own package and its libraries are found.

2 · Hook 2 min

Your function calls an AI model. Every test run costs money, takes seconds, and the answer is a little different each time. How can a test say “pass” or “fail” and mean it?

Guess first, then open

Do not call the real model in a test. Hand the function a fake that returns a fixed answer. The test runs in a blink, for free, and gives the same result every time.

3 · The idea, in three small pieces 8 min

Piece 1: a test is a small function that checks one thing

pytest runs every function named test_... in files named test_....py. Inside, assert says what must be true. No error means pass. A broken assert means fail, and pytest shows you why.

Piece 2: hand the helper in, so a test can swap it

Instead of creating the AI client inside the function, take it as a parameter: summarize(text, client). In real life you pass the real client. In a test you pass a fake, a tiny class with the same method that returns what you choose. This habit is called dependency injection, which just means “hand it in”.

Piece 3: test the failure too

A good set of tests has a normal case, an edge case (an unusual input, like empty text), and an error case. with pytest.raises(ValueError): passes only if that error really happens.

If you know another typed language (C# as the example): a test_ function is your [Fact] (xUnit) or [Test] (NUnit). assert is Assert.Equal, and pytest.raises is Assert.Throws. A fake class does the job of Moq or NSubstitute, and passing it as a parameter is constructor injection in a lighter form. A Protocol is like an interface, but a class fits it just by having the right method; it does not need to say “implements”.
Capstone: every test in the project will run with no network and no API key, so they can run in CI for free. Real model calls are checked separately, later, with evaluation.

4 · Worked example 3 min

Read it first. A function that asks a model for a summary, and a test file with a fake model.

src/my_ai_project/summarizer.py

from typing import Protocol


class LlmClient(Protocol):
    def complete(self, prompt: str) -> str: ...


def summarize(text: str, client: LlmClient, max_words: int = 20) -> str:
    if not text.strip():
        raise ValueError("text must not be empty")
    reply = client.complete(f"Summarize in one sentence: {text}")
    return " ".join(reply.split()[:max_words])

tests/test_summarizer.py

import pytest

from my_ai_project.summarizer import summarize


class FakeClient:
    def __init__(self, reply: str) -> None:
        self.reply = reply
        self.prompts: list[str] = []

    def complete(self, prompt: str) -> str:
        self.prompts.append(prompt)
        return self.reply


def test_returns_the_reply() -> None:
    client = FakeClient("  A short summary.  ")
    assert summarize("Some long text", client) == "A short summary."


def test_cuts_long_replies() -> None:
    client = FakeClient("one two three four five six")
    assert summarize("text", client, max_words=3) == "one two three"


def test_sends_the_text_to_the_model() -> None:
    client = FakeClient("ok")
    summarize("error E101", client)
    assert "error E101" in client.prompts[0]


def test_empty_text_raises() -> None:
    with pytest.raises(ValueError):
        summarize("   ", FakeClient("x"))

Solution

src/my_ai_project/summarizer.py

import logging
from typing import Protocol

logger = logging.getLogger("summarizer")


class LlmClient(Protocol):
    def complete(self, prompt: str) -> str: ...


def summarize(text: str, client: LlmClient, max_words: int = 20) -> str:
    if not text.strip():
        raise ValueError("text must not be empty")
    reply = client.complete(f"Summarize in one sentence: {text}")
    return " ".join(reply.split()[:max_words])


def summarize_or_default(text: str, client: LlmClient) -> str:
    try:
        return summarize(text, client)
    except TimeoutError as err:
        logger.warning("model timed out: %s", err)
        return "Summary not available."

tests/test_solution.py

from my_ai_project.summarizer import summarize_or_default


class FailingClient:
    def complete(self, prompt: str) -> str:
        raise TimeoutError("model too slow")


class FakeClient:
    def complete(self, prompt: str) -> str:
        return "A fine summary."


def test_timeout_gives_the_default() -> None:
    assert summarize_or_default("text", FailingClient()) == "Summary not available."


def test_normal_reply_still_works() -> None:
    assert summarize_or_default("text", FakeClient()) == "A fine summary."

6 · Stuck? anytime

  • “pytest: command not found”, or a wall of collection errors: run it as uv run pytest from the folder with pyproject.toml, and make sure you ran uv add --dev pytest.
  • “No module named pytest”: you used plain python3 -m pytest. Use uv run pytest.
  • pytest runs fewer tests than you wrote: the file must be named test_something.py and each function must start with test_. Otherwise pytest silently skips it.
  • Your change does not show up: save the file first.
  • “nothing to commit”: you did not save the files, or you are in the wrong folder.

7 · Check yourself 5 min

  1. Why do we pass the client into summarize instead of creating it inside?
  2. What does pytest.raises(ValueError) check?
  3. A test fails with DID NOT RAISE. What does that tell you?
Answers
  1. So a test can hand in a fake. The test then needs no network, no API key and no money, and gives the same answer every time.
  2. That the code inside the with block raises that error. If it does not, the test fails.
  3. The code that should have failed ran without an error: a check is missing or too weak.
