Answer from memory, then open the answers.

  1. Name the three levers that limit excessive agency.
  2. Why is a person who approves every action not enough?
Answers
  1. Permissions (what it may do), autonomy (how much without asking), blast radius (how much damage in one run, for example a budget).
  2. People get tired and click yes. A budget and least privilege cover the case where they do.

2 · The goal 5 min

This is the Module 11 checkpoint: one guardrail and one audit log. By the end:

  • The guardrail: an allow-list for tool arguments. A call with an unexpected tool, an unexpected argument or a value that does not match is blocked before it runs, with a clear error the model can read.
  • The audit log: one JSON line for every question and every tool call, with the role, the time, the arguments, the outcome (ok, error, blocked) and the reason; private strings hidden; append-only; it never breaks a request.
  • The proof: one blocked call and its log line, shown.
Capstone: this is the security story of ai-knowledge-assistant for a reviewer: “I assume the model can be fooled; here is what stops it, here is the record, and here is the gap I know about.”
What is real, and what is not. The guardrail, the log and the tests are real code. The model that asks for the bad call is a hostile stand-in (it asks for a given call, whatever the user wrote): it is not a real model, and that is the point. We test the system on the assumption that the model gives way. The role still comes from a forgeable demo header: the README says so.

import re
from typing import Any
from urllib.parse import urlparse

# An allow-list, not a deny-list: only what is written here is accepted. ASCII digits only ([0-9], not \d, which also matches other scripts).
ALLOWED_ARGUMENTS: dict[str, dict[str, re.Pattern[str]]] = {
    "lookup_error": {"code": re.compile(r"[Ee][0-9]{3}")},
    "close_incident": {"code": re.compile(r"[Ee][0-9]{3}")},
    "list_error_codes": {},
}
HINTS = {
    "lookup_error": "send only the argument 'code': the letter E and three digits, like E104",
    "close_incident": "send only the argument 'code': the letter E and three digits, like E104",
    "list_error_codes": "send no arguments",
}
INJECTION_PATTERNS = [
    re.compile(r"ignore\s+(all\s+)?(the\s+)?(previous|prior|above|earlier)\s+(instructions|rules|prompts?)", re.IGNORECASE),
    re.compile(r"disregard\s+(all\s+)?(the\s+)?(previous|prior|above|earlier|your)\s+(instructions|rules)", re.IGNORECASE),
    re.compile(r"(reveal|show|print)\s+(your\s+|the\s+)?system\s+prompt", re.IGNORECASE),
]
URL = re.compile(r"https?://[^\s)>\]\"']+", re.IGNORECASE)
ALLOWED_DOMAINS = ("pumpguard.example",)


def hint_for(name: str) -> str:
    return HINTS.get(name, "this tool has no argument policy")


def check_arguments(name: str, tool_input: dict[str, Any]) -> str | None:
    """Return a reason if the call must be blocked, or None. Unknown tools and unexpected arguments are blocked (fail closed)."""
    allowed = ALLOWED_ARGUMENTS.get(name)
    if allowed is None:
        return f"there is no argument policy for the tool {name!r}"
    unexpected = sorted(set(tool_input) - set(allowed))
    if unexpected:
        return f"the argument {unexpected[0]!r} is not allowed for {name}"
    for key, pattern in allowed.items():
        if key in tool_input and not (isinstance(tool_input[key], str) and pattern.fullmatch(tool_input[key])):
            return f"the argument {key!r} does not match the allow-list for {name}"
    return None


def check_output(text: str, allowed_domains: tuple[str, ...] = ALLOWED_DOMAINS) -> str | None:
    """Return a reason if an answer links to a site that is not on the allow-list. It only sees full http(s) links: a first layer, not a wall."""
    for link in URL.findall(text):
        host = (urlparse(link).hostname or "").lower()
        if not any(host == domain or host.endswith("." + domain) for domain in allowed_domains):
            return f"the answer links to {host or link!r}, which is not on the allow-list"
    return None


def scan_for_injection(text: str) -> str | None:
    """A weak, cheap check for text that talks TO the model instead of ABOUT the product. Easy to get around: use it to warn, never to trust."""
    for pattern in INJECTION_PATTERNS:
        found = pattern.search(text)
        if found:
            return f"looks like an instruction to the model: {found.group(0)!r}"
    return None

Step 2: the audit log

It replaces question_log.py. One class for every event:

import json
import logging
import re
from datetime import datetime, timezone
from pathlib import Path

logger = logging.getLogger("audit")

EMAIL = re.compile(r"[\w.+-]+@[\w-]+\.[\w.-]+")
KEY = re.compile(r"\b(?:sk|pk|key)-[A-Za-z0-9_-]{12,}")


def redact(value: object) -> object:
    """Hide the most common private strings (emails, API-key shapes) before anything is written. A safety net, not a guarantee."""
    if isinstance(value, str):
        return KEY.sub("[key]", EMAIL.sub("[email]", value))
    if isinstance(value, dict):
        return {k: redact(v) for k, v in value.items()}
    if isinstance(value, list):
        return [redact(v) for v in value]
    return value


class AuditLog:
    """An append-only record of what happened: every question, every tool call, and what was blocked. One JSON line per event."""

    def __init__(self, path: Path) -> None:
        self.path = path

    def record(self, event: str, role: str, **details: object) -> None:
        """Never raises: a log that cannot be written must not cost the user their answer."""
        line = {"time": datetime.now(timezone.utc).isoformat(), "event": event, "role": role, **{k: redact(v) for k, v in details.items()}}
        try:
            self.path.parent.mkdir(parents=True, exist_ok=True)
            with self.path.open("a", encoding="utf-8") as file:
                file.write(json.dumps(line) + "\n")
        except OSError as err:
            logger.warning("could not write the audit log %s: %s", self.path, err)
