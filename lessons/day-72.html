2 · Hook 2 min

Your assistant says “Calibrate once a month.” A user asks: “Where does it say that?” Can your app answer, and can it tell if the answer was made up?

Guess first, then open

Only if every answer carries where it came from. A citation such as [manual-calibration#0] lets the user open the page, and lets your code check that the page was really one of the chunks you gave to the model. An answer with no citation, or with one you never gave, should not be shown.

3 · The idea, in three small pieces 8 min

Piece 1: grounding means “only from these sources”

A grounded answer is built from the chunks you retrieved, not from what the model remembers. You do two things in the prompt: you give the chunks as numbered sources, each with its citation ([doc_id#chunk_index]), and you write the rule: use only these sources, cite each fact, and say “not found” if the sources do not have the answer. The rules go in the system prompt; the sources and the question go in the user message.

Piece 2: the citation is the chunk’s id

You already made the id on Day 67: doc_id plus chunk_index. The model does not invent the id format; it copies it from the source line. That is why you show the id exactly as written.

Piece 3: check the citations in code

A model can still cite something that was never in the prompt. So after the answer, find every [...] with a regular expression and check that each id is in the set of chunks you retrieved. Ids that are not there are invented citations. Real citations become the Sources line you show to the user.

If you know another typed language (C# as the example): the citation check is like validating a foreign key: every reference in the output must exist in the set you passed in. cited_ids is a Regex.Matches(...).Select(...).Distinct(), and the dataclass is a record with a computed property.
Capstone: in ai-knowledge-assistant a reader must be able to check every answer. This is the part that makes it possible, and on Saturday it sits in the real pipeline.

4 · Worked example 5 min

Read it first. A new module src/my_ai_project/grounding.py: the rules, a function that builds the numbered message, and ground, which calls the writer and checks the citations:

import re
from dataclasses import dataclass
from typing import Protocol

from my_ai_project.prompts import NO_ANSWER
from my_ai_project.store import Found

RULES = f"""You are a support assistant for the PumpGuard monitor.

Rules:
1. Use only the sources in the user message. Do not use any other knowledge.
2. Answer in at most two short sentences.
3. After each fact, add the citation of its source, exactly as written, like [error-e101#0].
4. If the sources do not contain the answer, reply with exactly: {NO_ANSWER}"""

CITATION = re.compile(r"\[([a-z0-9-]+#\d+)\]")


class Writer(Protocol):
    def complete(self, prompt: str, system: str | None = None) -> str: ...


@dataclass
class GroundedAnswer:
    text: str
    sources: list[Found]  # the retrieved chunks that the answer really cites
    invented: list[str]  # citations in the text that are not in the retrieved set

    @property
    def refused(self) -> bool:
        return self.text.strip() == NO_ANSWER


def build_message(question: str, found: list[Found]) -> str:
    """The user message: numbered sources, then the question. The rules go in the system prompt."""
    sources = "\n".join(f"{f.citation} {f.title}. {f.text}" for f in found)
    return f"Sources:\n{sources}\n\nQuestion: {question}"


def cited_ids(text: str) -> list[str]:
    """The citations in an answer, without the brackets, once each, in order."""
    return list(dict.fromkeys(CITATION.findall(text)))


def ground(question: str, found: list[Found], writer: Writer) -> GroundedAnswer:
    text = writer.complete(build_message(question, found), RULES).strip()
    by_id = {f"{f.doc_id}#{f.chunk_index}": f for f in found}
    ids = cited_ids(text)
    return GroundedAnswer(text, [by_id[i] for i in ids if i in by_id], [i for i in ids if i not in by_id])
This writer is simulated. We have no key in this lesson, so we use SimulatedWriter: a small class that reads the numbered sources and writes the first sentence of the top source with its citation. It is not a real model and a real model will word things differently. With careless=True it also cites a source that was never given, to show you what the check catches. Add it to simulated.py:
class SimulatedWriter:
    """A stand-in for a real model that follows the numbered-source prompt of Day 72: no key, no cost.

    It is NOT a real model. It answers with the first sentence of the top source and its citation, and it says
    "not found" only when no word of the question appears in that source. A real model is less predictable.
    With careless=True it also cites a source that was never given: the mistake that grounding must catch."""

    def __init__(self, careless: bool = False) -> None:
        self.careless = careless

    def complete(self, prompt: str, system: str | None = None) -> str:
        question = prompt.rsplit("Question:", 1)[1].strip()
        sources = re.findall(r"^\[([a-z0-9-]+#\d+)\] (.+)$", prompt, re.MULTILINE)
        words = {w for w in re.findall(r"[a-z0-9]+", question.lower()) if len(w) >= 4 and w not in STOP_WORDS}
        top_id, top_text = sources[0] if sources else ("", "")
        if not any(word in top_text.lower() for word in words):
            return NO_ANSWER
        body = top_text.split(". ", 1)[1] if ". " in top_text else top_text
        sentence = body.split(". ")[0].rstrip(".") + "."
        text = sentence[:-1] + f" [{top_id}]."
        if self.careless:
            text += " Contact support if it keeps happening [faq-support#0]."
        return text

A script that retrieves, builds the prompt, and asks both writers. ask_with_sources.py:

import os

from my_ai_project.embedder import FastEmbedder
from my_ai_project.grounding import RULES, build_message, ground
from my_ai_project.pipeline import retrieve
from my_ai_project.simulated import SimulatedWriter
from my_ai_project.store import ChunkStore

store = ChunkStore(os.environ.get("DATABASE_URL", "postgresql://assistant:assistant@localhost:5433/assistant"))
embedder = FastEmbedder()
question = "How often should I calibrate the sensor?"

found = retrieve(question, embedder, store, top_k=3)
print("--- system prompt ---")
print(RULES)
print("--- user message ---")
print(build_message(question, found))

for writer in (SimulatedWriter(), SimulatedWriter(careless=True)):
    answer = ground(question, found, writer)
    print(f"\n--- {'careless' if writer.careless else 'careful'} writer ---")
    print("Answer:", answer.text)
    print("Sources:", ", ".join(f"{s.citation} {s.title}" for s in answer.sources) or "none")
    print("Invented citations:", answer.invented or "none")

6 · Stuck? anytime

  • The citation is not found (invented has the id of a real source): check that you copy the id the same way in the prompt and in the regex. The id is doc_id#chunk_index, in square brackets, lower case.
  • The answer has no citation: the writer did not follow rule 3. In this lesson that means your RULES text was changed. Keep rule 3 exactly.
  • “ModuleNotFoundError ... grounding”: the file must be in src/my_ai_project/.
  • The sources look wrong: you may have an old table without the kind and title columns. Run ingest.py from Day 67 again.
Hint: Step 4

The sources of an answer are answer.sources, each a Found with citation and title. Join them with a newline and start each line with two spaces. If the list is empty, return an empty string.

The Sources line would show faq-support#0, a page that is not in your knowledge base. That is worse than no sources: it looks like proof and sends the user to nothing. A missing citation is honest; an invented one is a lie with a stamp on it.

Template: tests
from my_ai_project.grounding import GroundedAnswer, build_message, cited_ids, ground
from my_ai_project.prompts import NO_ANSWER
from my_ai_project.simulated import SimulatedWriter
from my_ai_project.store import Found

FOUND = [
    Found("faq-battery", 0, "Battery life", "faq", "The battery lasts about eight hours. Charge it every night.", 0.8),
    Found("error-e102", 0, "E102 Battery low", "error", "The battery is under 15 percent. Connect the power cable.", 0.7),
]


class Reply:
    def __init__(self, text: str) -> None:
        self.text = text

    def complete(self, prompt: str, system: str | None = None) -> str:
        return self.text


def test_the_message_numbers_every_source() -> None:
    message = build_message("How long?", FOUND)
    assert "[faq-battery#0] Battery life. The battery lasts about eight hours." in message
    assert "[error-e102#0] E102 Battery low." in message
    assert message.endswith("Question: How long?")


def test_cited_ids_are_unique_and_in_order() -> None:
    assert cited_ids("A [error-e102#0]. B [faq-battery#0]. C [error-e102#0].") == ["error-e102#0", "faq-battery#0"]
    assert cited_ids("no citation here") == []


def test_a_good_answer_keeps_its_sources() -> None:
    answer = ground("How long?", FOUND, Reply("About eight hours [faq-battery#0]."))
    assert [s.doc_id for s in answer.sources] == ["faq-battery"]
    assert answer.invented == []


def test_an_invented_citation_is_reported_and_not_kept() -> None:
    answer = ground("How long?", FOUND, Reply("About eight hours [faq-battery#0]. Call us [faq-support#0]."))
    assert answer.invented == ["faq-support#0"]
    assert [s.doc_id for s in answer.sources] == ["faq-battery"]


def test_a_refusal_is_recognised() -> None:
    assert ground("How long?", FOUND, Reply(NO_ANSWER)).refused
    assert not GroundedAnswer("About eight hours [faq-battery#0].", [], []).refused


def test_the_simulated_writer_cites_its_top_source() -> None:
    answer = ground("How long does the battery last?", FOUND, SimulatedWriter())
    assert answer.text == "The battery lasts about eight hours [faq-battery#0]."
