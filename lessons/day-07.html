3 · The idea, in three small pieces 8 min

Piece 1: write the finish line first

A lab is a build session, not a lecture. Before you type, write what done looks like in words. Today: one command prints a title and the reading time, the tests pass, mypy is quiet, and the work is merged. If you cannot say it, you cannot tell when you are finished.

Piece 2: check the data at the door

A file is just text. Turn it into a Document (a Pydantic model, Day 3) once, at the door. After that the rest of the code can trust that every document has an id and a title.

Piece 3: tests get their own temporary folder

A test that reads files should never touch your real folders. pytest gives each test an empty temporary folder through a parameter called tmp_path. The test writes a tiny file there, loads it, and the folder disappears after.

If you know another typed language (C# as the example): Path from pathlib does the job of System.IO.Path and File together. tmp_path is like a temp directory that xUnit would clean up for you. python -m my_ai_project runs the package like a small console app with a Main.
Capstone: this is the first real feature of the AI knowledge assistant. Later, RAG will split each Document into chunks and embed them. We keep the project name my-ai-project for now.

Step 3 The loader and a tiny command (40 min)

Replace documents.py again with the full version. New: a clear error type (Day 4), logging, and load_document that reads a Markdown file.

import logging
from pathlib import Path

from pydantic import BaseModel, Field

logger = logging.getLogger("documents")


class DocumentNotFoundError(Exception):
    """Raised when a document file does not exist."""


class Document(BaseModel):
    doc_id: str = Field(min_length=1)
    title: str = Field(min_length=1)
    body: str


def word_count(doc: Document) -> int:
    return len(doc.body.split())


def reading_minutes(doc: Document, words_per_minute: int = 200) -> float:
    return word_count(doc) / words_per_minute


def load_document(path: Path) -> Document:
    if not path.is_file():
        raise DocumentNotFoundError(f"no document at {path}")
    lines = path.read_text(encoding="utf-8").splitlines()
    if lines and lines[0].startswith("# "):
        title = lines[0].removeprefix("# ").strip()
        body = "\n".join(lines[1:]).strip()
    else:
        title = path.stem
        body = "\n".join(lines).strip()
    logger.info("loaded %s (%d words)", path.name, len(body.split()))
    return Document(doc_id=path.stem, title=title, body=body)

Create the knowledge file knowledge/error-e101.md (a knowledge folder next to pyproject.toml):

The sensor did not answer within ten seconds. Check the cable, then restart the sensor service. If the error comes back, open a ticket and write down the time it happened.

Create src/my_ai_project/__main__.py. This is what python -m my_ai_project runs:

import logging
import sys
from pathlib import Path

from my_ai_project.documents import DocumentNotFoundError, load_document, reading_minutes

logging.basicConfig(level=logging.INFO, format="%(levelname)s %(name)s: %(message)s")
logger = logging.getLogger("cli")


def main() -> int:
    if len(sys.argv) != 2:
        print("usage: python -m my_ai_project <file.md>")
        return 2
    try:
        doc = load_document(Path(sys.argv[1]))
    except DocumentNotFoundError as err:
        logger.warning("%s", err)
        print("Sorry, I could not find that file.")
        return 1
    print(f"{doc.title} ({reading_minutes(doc):.1f} min read)")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

Step 4 Your turn: the tests (40 min)

  1. (model) load_document reads the title and the body of a file that starts with # Error E101.
  2. A file with no # first line gets its file name (without .md) as the title.
  3. A missing file raises DocumentNotFoundError.
  4. reading_minutes of a 400-word document is 2.0.

def test_load_document_reads_title_and_body(tmp_path: Path) -> None:
    file = tmp_path / "error-e101.md"
    file.write_text("# Error E101\n\nCheck the cable.\n", encoding="utf-8")
    doc = load_document(file)
    assert doc.doc_id == "error-e101"
    assert doc.title == "Error E101"
    assert doc.body == "Check the cable."

For errors, use with pytest.raises(DocumentNotFoundError): (Day 5). For the empty title, the error type is pydantic.ValidationError.

Hint 2

Import what you need at the top: from pathlib import Path, import pytest, from pydantic import ValidationError, and the names from my_ai_project.documents.

from pathlib import Path

import pytest
from pydantic import ValidationError

from my_ai_project.documents import (
    Document,
    DocumentNotFoundError,
    load_document,
    reading_minutes,
)


def test_load_document_reads_title_and_body(tmp_path: Path) -> None:
    file = tmp_path / "error-e101.md"
    file.write_text("# Error E101\n\nCheck the cable.\n", encoding="utf-8")
    doc = load_document(file)
    assert doc.doc_id == "error-e101"
    assert doc.title == "Error E101"
    assert doc.body == "Check the cable."


def test_load_document_uses_the_file_name_when_there_is_no_title(tmp_path: Path) -> None:
    file = tmp_path / "faq.md"
    file.write_text("Just some text.", encoding="utf-8")
    assert load_document(file).title == "faq"


def test_missing_file_raises_a_clear_error(tmp_path: Path) -> None:
    with pytest.raises(DocumentNotFoundError):
        load_document(tmp_path / "nope.md")


def test_reading_minutes() -> None:
    doc = Document(doc_id="1", title="Guide", body="word " * 400)
    assert reading_minutes(doc) == 2.0


def test_document_needs_a_title() -> None:
    with pytest.raises(ValidationError):
        Document(doc_id="1", title="", body="text")

6 · Stuck? anytime

  • “Sorry, I could not find that file” but the file is there: the path is relative to the folder you are in. Run the command from the project folder, the one with pyproject.toml.
  • A ValidationError about title: title may not be empty. In a file the title comes from a first line that starts with # (hash and a space).
  • mypy says expected "Path": wrap the text with Path(...). Do not silence the checker.
  • pytest runs 0 tests: file and function names must start with test_ (Day 5).
  • “No module named pydantic”: run uv add pydantic, and use uv run, not plain python3.
  • Merge conflict: you changed the same lines on main and on the branch. Day 6 shows how to read the markers.

7 · Check yourself 5 min

  1. Why does load_document raise DocumentNotFoundError instead of returning None?
  2. Why do the tests write files into tmp_path?
  3. Why check the data inside Document, and not everywhere the document is used?
Answers
  1. A clear error with a name and message says what went wrong. A silent None moves the problem somewhere else, later.
  2. Each test gets its own empty temporary folder, so tests never touch your real files and never affect each other.
  3. One place checks, and the rest of the code can trust the object. Fewer checks, fewer bugs.
