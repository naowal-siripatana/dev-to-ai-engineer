Tokens and context windows

50-60 minhands-onfree
Today you will be able to count the tokens of a document in code and say how much of a context window it uses.

1 · Warm-up 3 min

Answer from memory, then open the answers.

  1. What is the one question a language model answers, and how does it write a whole sentence?
  2. Why did the toy model fall into a loop, and what do real models do about it?
Answers
  1. “Which token comes next?” It writes by repeating: score every possible next token, pick one, add it to the text, and predict again.
  2. It always picked the most common next token. Real models sample: they pick randomly, with more likely tokens picked more often.

2 · Hook 2 min

You pay for an AI call by the token, and every model has a limit in tokens. Yet you write text in characters and words. How long is “a token”, and is it the same for English, Thai and a JSON snippet?

Guess first, then open

No. A token is a piece of text, often a word or part of a word, and how text is cut depends on the language and on the model. English is usually cheap, other scripts can cost more, and JSON with quotes and braces costs more than you expect. Today you count tokens in code, so you stop guessing.

3 · The idea, in three small pieces 8 min

Piece 1: the token is the unit

A tokenizer cuts text into tokens, and each token has a number. A token is not a character and not a word: The is one token, sensor (with its space) is one, a long word may be two or three, and an unusual word can be cut into many small pieces. As a very rough rule, English text is about 4 characters per token, but you should measure, not guess.

Piece 2: the context window is a budget for one call

The context window is the most tokens a model can handle in one call. Your prompt (the question, the instructions, the documents you add) and the model’s answer share it. If your prompt fills the whole window, there is no room left for an answer. Text beyond the limit is rejected or cut, depending on the provider.

Piece 3: tokens are cost and speed

Providers charge per million tokens, usually a lower price for input and a higher one for output. More tokens also means a slower answer. So “put the whole knowledge base into every prompt” is not only a limit problem, it is a cost problem. (Prices differ by provider and change often. Always read the provider’s pricing page.)

If you know another typed language (C# as the example): count_tokens is text.Length for an LLM, except that it depends on the model: a different tokenizer gives a different count for the same text, like measuring in bytes in different encodings. The context window is a hard buffer size that you must check before you send.
Capstone: your knowledge base will hold far more text than one call can take. Counting tokens tells you how to cut documents into pieces, and how many pieces you can afford to send per question. That is the start of retrieval in module 6.

4 · Worked example 5 min

Read it first. We use tiktoken, a small library that holds a tokenizer. The encoding o200k_base is the one used by recent OpenAI models. Other providers use other tokenizers, so treat the numbers as a good estimate, and use your provider’s own counter when you need the exact number. src/my_ai_project/tokens.py:

import tiktoken

ENCODING = tiktoken.get_encoding("o200k_base")


def count_tokens(text: str) -> int:
    return len(ENCODING.encode(text))

A script to look at a few strings. show_tokens.py:

from my_ai_project.tokens import count_tokens

samples = [
    "The sensor timed out.",
    "E101",
    "internationalization",
    "1234567890",
    "เซ็นเซอร์หมดเวลา",
    '{"error_code": "E101", "severity": "medium"}',
]
for text in samples:
    print(f"{len(text):>3} characters {len(text.split()):>2} words {count_tokens(text):>3} tokens  {text}")
You should see

  4 characters  1 words   2 tokens  E101
20 characters  1 words   2 tokens  internationalization

The first time you use tiktoken it downloads the encoding file, so you need an internet connection once. After that it is cached. The Thai sentence has 16 characters but 6 tokens with this encoding.

6 · Stuck? anytime

  • The first run is slow or fails with a network error: tiktoken downloads the encoding the first time. Check your connection and try again.
  • “ModuleNotFoundError: No module named 'tiktoken'”: run uv add tiktoken, and run scripts with uv run.
  • Your numbers differ from the lesson: check the encoding name. Different encodings, and different tiktoken versions, can give slightly different counts.
  • “FileNotFoundError ... data/kb”: run from the project folder, with the 20 documents from Day 28 in data/kb.
Hint: Step 4

Load the documents with load_knowledge_base(Path("data/kb")), and loop over them with count_tokens(document.body). Keep a running total. For the window, the room for your prompt is WINDOW - RESERVED_FOR_ANSWER.

Solution: Step 4
from pathlib import Path

from my_ai_project.knowledge_base import load_knowledge_base
from my_ai_project.tokens import count_tokens

documents = load_knowledge_base(Path("data/kb"))
total = 0
for document in documents:
    tokens = count_tokens(document.body)
    total += tokens
    print(f"{document.doc_id:<28} {len(document.body):>4} characters {tokens:>4} tokens")
print("total:", total, "tokens in", len(documents), "documents")
print("average characters per token:", round(sum(len(d.body) for d in documents) / total, 2))

7 · Check yourself 5 min

  1. Why is a token not the same as a word or a character?
  2. What shares the context window, and what happens if the prompt fills all of it?
  3. Why can the same text have a different token count for two different models?
Answers
  1. A tokenizer cuts text into pieces that it learned are common: a whole word, part of a word, a space plus a word, a number, a symbol. So the count depends on the text, and a word can be one token or several.
  2. The prompt (question, instructions, documents) and the model’s answer share it. If the prompt fills the window, there is no room for an answer, and the call fails or the text is cut.
  3. Each model family has its own tokenizer, with its own table of pieces. The same Thai sentence was 6 tokens with one encoding and 18 with another.
