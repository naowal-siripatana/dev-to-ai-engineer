Today you will be able to score your pipeline on 18 questions with one table, find a failure in it, try a fix, and check that nothing else got worse.

1 · Warm-up 5 min

Answer from memory, then open the answers.

  1. Why are the exact phrase checks sometimes too strict?
  2. Why does the golden loader refuse a refusal question that has expected sources?
Answers
  1. A good answer can word a fact in a way that does not contain your phrase (a paraphrase), and it would fail unfairly.
  2. It contradicts itself: you cannot expect a page to be found for a question the assistant should refuse.

2 · The goal 5 min

This is the Module 8 checkpoint. By the end:

  • data/golden.jsonl: 18 questions with expected sources (15 to answer, 3 to refuse).
  • run_golden.py: a script that runs every question through the real pipeline and prints one score table: hit@3, rank, refusals, pass or fail with the reason, and a summary (pass rate, hit@3, MRR, refusal accuracy). It writes a JSON report, and can act as a gate (exit code 1 below a minimum).
  • The loop of evaluation-driven work: baseline, read the failures, change one thing, run again, compare.
Capstone: from now on, every change to ai-knowledge-assistant is judged by this table, and the table is part of your story for a reviewer: “I measured it, and here is what failed.”
What is real, and what is not. The retrieval numbers (hit@3, rank, MRR) are real: real embeddings in PostgreSQL with pgvector. The answers come from the simulated writer (a stand-in that writes the first sentence of the top page, NOT a real model). So the failures marked “the answer lacks ...” belong to that stand-in. With a real model they will be different, and you should run the script with one when you can.

Step 2: scoring

src/my_ai_project/scoring.py. One question gives a Result. The rule for a pass is simple and strict, and the why names the first thing that failed:

from dataclasses import asdict, dataclass

from my_ai_project.golden import GoldenItem


@dataclass
class Outcome:
    """What the pipeline did for one golden question."""

    item: GoldenItem
    retrieved: list[str]   # doc ids of the retrieved chunks, best first, each once
    answer: str
    refused: bool
    cited: list[str]       # doc ids that the answer cites


@dataclass
class Result:
    id: str
    hit: bool | None            # None for a question that should be refused
    rank: int | None            # 1 = the first retrieved page was expected; None = not retrieved
    refusal_ok: bool            # did it refuse exactly when it should?
    citation_ok: bool | None    # every cited page is an expected one (None when nothing to check)
    contains_ok: bool | None    # every required phrase is in the answer (None when nothing to check)
    passed: bool
    why: str                    # the first thing that failed, or ""


@dataclass
class Summary:
    total: int
    passed: int
    pass_rate: float
    hit_rate: float             # over the answerable questions
    mrr: float                  # mean reciprocal rank, over the answerable questions
    refusal_accuracy: float     # over all questions


def rank_of(expected: list[str], retrieved: list[str]) -> int | None:
    for position, doc_id in enumerate(retrieved, start=1):
        if doc_id in expected:
            return position
    return None


def score_one(outcome: Outcome) -> Result:
    item = outcome.item
    refusal_ok = outcome.refused == item.should_refuse
    if item.should_refuse:
        return Result(item.id, None, None, refusal_ok, None, None, refusal_ok, "" if refusal_ok else "answered a question that should be refused")
    rank = rank_of(item.expected_sources, outcome.retrieved)
    hit = rank is not None
    if outcome.refused:
        return Result(item.id, hit, rank, False, None, None, False, "refused a question that can be answered")
    wrong = [doc for doc in outcome.cited if doc not in item.expected_sources]
    citation_ok = not wrong
    missing = [phrase for phrase in item.must_contain if phrase.lower() not in outcome.answer.lower()]
    contains_ok = not missing
    why = ""
    if not hit:
        why = "no expected source in the retrieved pages"
    elif not citation_ok:
        why = f"cited a page that is not expected: {wrong[0]}"
    elif not contains_ok:
        why = f"the answer lacks {missing[0]!r}"
    return Result(item.id, hit, rank, True, citation_ok, contains_ok, why == "", why)


def summarize(results: list[Result]) -> Summary:
    answerable = [r for r in results if r.hit is not None]
    total = len(results)
    passed = sum(r.passed for r in results)
    return Summary(
        total=total,
        passed=passed,
        pass_rate=passed / total if total else 0.0,
        hit_rate=sum(bool(r.hit) for r in answerable) / len(answerable) if answerable else 0.0,
        mrr=sum(1 / r.rank for r in answerable if r.rank) / len(answerable) if answerable else 0.0,
        refusal_accuracy=sum(r.refusal_ok for r in results) / total if total else 0.0,
    )


def to_report(results: list[Result], summary: Summary) -> dict[str, object]:
    return {"summary": asdict(summary), "results": [asdict(r) for r in results]}

run_golden.py:

import argparse
import json
import os
from pathlib import Path

from my_ai_project.access import allowed_kinds
from my_ai_project.embedder import FastEmbedder
from my_ai_project.golden import GoldenError, load_golden
from my_ai_project.hybrid import KeywordIndex, hybrid_search
from my_ai_project.rag import answer_question
from my_ai_project.scoring import Outcome, score_one, summarize, to_report
from my_ai_project.simulated import SimulatedWriter
from my_ai_project.store import ChunkStore

parser = argparse.ArgumentParser(description="Run the golden questions through the RAG pipeline and score them.")
parser.add_argument("--golden", default="data/golden.jsonl")
parser.add_argument("--role", default="staff")
parser.add_argument("--keyword-weight", type=float, default=1.0, help="below 1 trusts the keyword search less")
parser.add_argument("--report", default="reports/golden-latest.json")
parser.add_argument("--min-pass", type=float, default=0.0, help="exit with 1 if the pass rate is lower (a regression gate)")
args = parser.parse_args()

store = ChunkStore(os.environ.get("DATABASE_URL", "postgresql://assistant:assistant@localhost:5433/assistant"))
chunks = store.all_chunks()
try:
    items = load_golden(Path(args.golden), {chunk.doc_id for chunk in chunks})
except GoldenError as err:
    raise SystemExit(f"golden file is wrong: {err}")

embedder, keywords, writer = FastEmbedder(), KeywordIndex(chunks), SimulatedWriter()   # the writer is a stand-in, NOT a real model
kinds = allowed_kinds(args.role)
results = []
print(f"{'id':<5}{'hit@3':<7}{'rank':<6}{'refused':<9}{'result':<7}why")
for item in items:
    found = hybrid_search(item.question, embedder, store, keywords, top_k=3, allowed_kinds=kinds, keyword_weight=args.keyword_weight)
    answer = answer_question(item.question, embedder, store, keywords, writer, top_k=3, allowed_kinds=kinds, keyword_weight=args.keyword_weight)
    outcome = Outcome(item, list(dict.fromkeys(f.doc_id for f in found)), answer.text, answer.refused, list(dict.fromkeys(s.doc_id for s in answer.sources)))
    result = score_one(outcome)
    results.append(result)
    hit = "-" if result.hit is None else ("yes" if result.hit else "no")
    print(f"{result.id:<5}{hit:<7}{str(result.rank or '-'):<6}{'yes' if outcome.refused else 'no':<9}{'pass' if result.passed else 'FAIL':<7}{result.why}")

summary = summarize(results)
print(f"\npassed {summary.passed}/{summary.total} ({summary.pass_rate:.0%})   hit@3 {summary.hit_rate:.0%}   MRR {summary.mrr:.2f}   refusal accuracy {summary.refusal_accuracy:.0%}")
Path(args.report).parent.mkdir(parents=True, exist_ok=True)
Path(args.report).write_text(json.dumps(to_report(results, summary), indent=2), encoding="utf-8")
if summary.pass_rate < args.min_pass:
    raise SystemExit(f"pass rate {summary.pass_rate:.0%} is under the minimum {args.min_pass:.0%}")

Step 4: tests

The scoring is pure code, so it is tested with made-up outcomes, with no database and no model:

from my_ai_project.golden import GoldenItem
from my_ai_project.scoring import Outcome, rank_of, score_one, summarize

ITEM = GoldenItem(id="q1", question="How often?", expected_sources=["manual-calibration"], must_contain=["once a month"])
REFUSE = GoldenItem(id="q2", question="Coffee?", should_refuse=True)


def outcome(item: GoldenItem, retrieved: list[str], answer: str = "", refused: bool = False, cited: list[str] | None = None) -> Outcome:
    return Outcome(item, retrieved, answer, refused, cited or [])


def test_rank_is_the_position_of_the_first_expected_page() -> None:
    assert rank_of(["a", "b"], ["x", "b", "a"]) == 2
    assert rank_of(["a"], ["x", "y"]) is None


def test_a_good_answer_passes() -> None:
    result = score_one(outcome(ITEM, ["manual-calibration"], "Calibrate once a month [x].", cited=["manual-calibration"]))
    assert result.passed and result.hit and result.rank == 1 and result.why == ""


def test_a_retrieval_miss_is_named() -> None:
    result = score_one(outcome(ITEM, ["faq-reset"], "Hold the button.", cited=["faq-reset"]))
    assert not result.passed and result.hit is False and "no expected source" in result.why


def test_a_wrong_citation_fails_even_when_the_page_was_retrieved() -> None:
    result = score_one(outcome(ITEM, ["faq-reset", "manual-calibration"], "once a month", cited=["faq-reset"]))
    assert not result.passed and result.hit and "not expected: faq-reset" in result.why


def test_a_missing_phrase_fails() -> None:
    result = score_one(outcome(ITEM, ["manual-calibration"], "Calibrate the sensor.", cited=["manual-calibration"]))
    assert not result.passed and "lacks 'once a month'" in result.why


def test_refusing_an_answerable_question_fails() -> None:
    result = score_one(outcome(ITEM, ["manual-calibration"], "not found", refused=True))
    assert not result.passed and result.refusal_ok is False and result.hit is True


def test_a_refusal_passes_only_when_the_assistant_refuses() -> None:
    assert score_one(outcome(REFUSE, [], "not found", refused=True)).passed
    wrong = score_one(outcome(REFUSE, ["faq-warranty"], "two years", cited=["faq-warranty"]))
    assert not wrong.passed and wrong.hit is None


def test_the_summary_counts_hits_over_answerable_questions_only() -> None:
    results = [
        score_one(outcome(ITEM, ["manual-calibration"], "once a month", cited=["manual-calibration"])),
        score_one(outcome(ITEM, ["x", "manual-calibration"], "once a month", cited=["manual-calibration"])),
        score_one(outcome(REFUSE, [], "not found", refused=True)),
    ]
    summary = summarize(results)
    assert summary.total == 3 and summary.passed == 3
    assert summary.hit_rate == 1.0 and summary.mrr == 0.75   # (1 + 1/2) / 2
    assert summary.refusal_accuracy == 1.0


def test_an_empty_run_does_not_divide_by_zero() -> None:
    assert summarize([]).pass_rate == 0.0

2. Find the cause of the retrieval miss (q14)

“How do I install the monitor?” found the reset page, not the install page. Print the two lists of the hybrid search for that question:

You should see
vector pool: manual-install#0 is FIRST
keyword pool: faq-reset, faq-alarm-sound, faq-battery-life, manual-safety, manual-firmware-update, ... (manual-install is not in it)

The vector search had the install page first. The keyword search did not have it at all, because the page never uses the word “install” (it says “Mount the monitor...”; and there is no stemming), and it ranked faq-reset first because its title (“How do I reset the monitor?”) shares the words how, do, i, the, monitor with the question. The fusion believed the keyword list, and the right page fell out of the top 3. Hybrid search made this question worse. You would never have seen it with five questions.

6 · Stuck? anytime

  • “golden file is wrong: ...”: the message names the question and the problem. Fix the file first.
  • Your numbers differ from mine: your knowledge base, chunking and questions differ. Compare your before and after.
  • Everything fails the phrase check: with the stand-in writer, only the first sentence of a page is in the answer. Put the phrase from the first sentence, or accept those failures as the writer’s.
  • You fixed one question and another broke: that is the lesson. Revert, and try a different fix.
  • A remote gate in CI: not today. First make the table trustworthy.
