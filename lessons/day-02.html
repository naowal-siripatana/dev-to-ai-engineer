DAY 2 · LEVEL 1: PYTHON

Project setup with uv

45-60 minhands-onfree
Today you will be able to create a Python project with uv, add a typed module, run it, and make your first Git commit.

1 · Warm-up 3 min

Answer both from memory, then open the answers.

  1. What does a type hint do while the program runs?
  2. Which tool can catch a wrong-typed call before you run the program?
Answers
  1. Nothing. Python ignores hints at runtime.
  2. mypy (or an editor that reads hints).

2 · Hook 2 min

Your code works on your laptop. Your friend installs it, and it breaks. Why?

Guess first, then open

Different Python version, missing packages, or files in different places. A project file and a lock file remove the guesswork. That is what uv gives you.

3 · The idea, in three small pieces 10 min

Piece 1: a project has an ID card

A project is a folder with a file called pyproject.toml. It says the project name, which Python it needs, and which packages it uses.

Piece 2: a private toolbox for each project

A virtual environment is a private toolbox: the packages of one project do not mix with another. uv makes it for you, and uv run always uses the right one.

Piece 3: put your code under src/

In a src-layout, your code lives in src/your_package/ and is imported as a package. If it is not installed, the import fails, which catches “it only works from this folder” mistakes early. uv run installs your package for you.

FileWhat it is for
pyproject.tomlThe ID card of the project
.python-versionWhich Python this project uses
src/my_ai_project/Your code (a package)
README.mdWords about the project
.gitignoreFiles Git should skip
If you know another typed language (C# as the example): pyproject.toml plays the role of a .csproj or package.json. uv add is like dotnet add package or npm install. A lock file (uv.lock) records exact versions, like package-lock.json.
Capstone: this is the folder that becomes the Python AI service of the project we build.

4 · Worked example 5 min

Read it first. These two commands create a whole project.

uv init --package my-ai-project --lib
cd my-ai-project
You should see
Initialized project `my-ai-project` at ...

Then your folder looks like this:

my-ai-project/
  .gitignore
  .python-version
  README.md
  pyproject.toml
  src/
    my_ai_project/
      __init__.py
      py.typed

5 · Try it 25-30 min

Four steps, from guided to free. Work in a normal folder (for example Projects) and open the new project folder in VS Code.

Step 1 Copy and run

Run the two commands from the worked example. Open the folder in VS Code and look at the files. Then check the import:

uv run python -c "import my_ai_project; print('imported ok')"
You should see
imported ok
(the first time, uv also prints that it built and installed your package)

The generated pyproject.toml says requires-python with your Python version. That is normal.

Step 2 Change one thing

Create src/my_ai_project/documents.py:

from dataclasses import dataclass


@dataclass
class Document:
    doc_id: str
    title: str
    body: str


def word_count(doc: Document) -> int:
    return len(doc.body.split())


def preview(doc: Document, max_words: int = 5) -> str:
    words = doc.body.split()
    text = " ".join(words[:max_words])
    return text + ("..." if len(words) > max_words else "")

Create try_documents.py in the project folder (next to pyproject.toml):

from my_ai_project.documents import Document, word_count, preview

d = Document(doc_id="1", title="Error codes", body="Error E101 means the sensor timed out after ten seconds.")
print(word_count(d))
print(preview(d))
print(preview(d, 3))

Before you run it, predict: what will preview(d, 3) print? Then run uv run python try_documents.py.

Check your prediction
You should see
10
Error E101 means the sensor...
Error E101 means...

The default is 5 words. With 3 words, it stops earlier and adds ....

Step 3 Break it on purpose

Try these two on purpose:

  1. Misspell the module: uv run python -c "from my_ai_project.document import Document"
  2. Run Python without uv: python3 -c "import my_ai_project"
You should see
1) ModuleNotFoundError: No module named 'my_ai_project.document'
2) ModuleNotFoundError: No module named 'my_ai_project'

In the first case you made a typo. In the second case, plain python3 does not know your project’s private toolbox. uv run does.

Optional: let mypy find a wrong-typed call. Create bad.py:

from my_ai_project.documents import Document, preview

d = Document(doc_id="1", title="t", body="a b c")
print(preview(d, "three"))

Run uv run --with mypy mypy bad.py (the --with flag borrows mypy for one run).

You should see
bad.py:4: error: Argument 2 to "preview" has incompatible type "str"; expected "int" [arg-type]

Step 4 Your turn

In a new file src/my_ai_project/documents_extra.py, write reading_minutes(doc: Document, words_per_minute: int = 200) -> float. It should return how many minutes a document takes to read. Test it with a document of 400 words: you should get 2.0.

Hint 1

You already have word_count(doc). Import it.

Hint 2

Minutes = words divided by words per minute.

Solution
from my_ai_project.documents import Document, word_count


def reading_minutes(doc: Document, words_per_minute: int = 200) -> float:
    return word_count(doc) / words_per_minute

Test file:

from my_ai_project.documents import Document
from my_ai_project.documents_extra import reading_minutes

d = Document("1", "Guide", "word " * 400)
print(reading_minutes(d))
You should see
2.0

Finally, save your work with Git. uv init already ran git init for you (look for the hidden .git folder). Make your first commit, and add a short Status line to README.md first (for example “Day 2: project set up with uv and one typed module”).

git add .
git commit -m "First commit"
git log --oneline
You should see
one line, like: 947c3d2 First commit (your number will differ)

If Git asks who you are, run git config --global user.name "Your Name" and git config --global user.email "you@example.com", then commit again.

6 · Stuck? anytime

  • “command not found: uv”: reopen the terminal, or redo the uv step of Day 0.
  • ModuleNotFoundError on a correct name: run it with uv run, from the project folder.
  • “nothing to commit”: you may have committed already. Run git log --oneline.
  • Still stuck? Comment on the video with the exact message you see.

7 · Check yourself 5 min

  1. What is pyproject.toml for?
  2. Why did python3 -c "import my_ai_project" fail, but uv run python -c ... worked?
  3. Why put the code under src/?
Answers
  1. It is the project’s ID card: name, Python version, and packages.
  2. Plain python3 does not use the project’s private environment, where your package is installed. uv run does.
  3. The code is importable only after it is installed. That catches “works only from this folder” mistakes early and keeps source files apart from other files.
