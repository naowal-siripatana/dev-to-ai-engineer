2 · Hook 2 min

A model decides to call lookup_error with {"code": "E104", "role": "admin"}. Your function ignores the extra argument, so nothing bad happens today. Why should you block it anyway, and how will you know it happened?

Guess first, then open

An argument that your tool does not expect is a sign that something is trying things, and tomorrow someone may add code that reads that argument. A strict allow-list accepts only what is written down and rejects the rest. And you will know because every call, allowed or blocked, goes into an audit log.

3 · The idea, in three small pieces 8 min

Piece 1: an allow-list, not a deny-list

A deny-list says what is forbidden, and attackers find what you forgot. An allow-list says what is accepted, and everything else is blocked. For a tool: which arguments it takes, and which values are acceptable for each (a pattern, a set). Unknown tools and unexpected arguments are blocked: fail closed. Be strict about the details: [0-9] and not \d, because in many regular-expression engines \d also matches digits from other scripts.

Piece 2: least privilege, everywhere

Give each part only what its job needs: a role for the user, only the needed arguments for the tool, only the needed tools and a budget for the agent, a database user that cannot drop tables, a key with a spending limit. When something goes wrong, the damage is the size of what you gave it. This is the same idea as the budget for risky calls you will see on Friday.

Piece 3: an audit log answers “what happened?”

Guardrails stop things; an audit log tells you what was tried, what was stopped, and by what. Record every question, every tool call (tool, arguments, outcome, reason) and every block, with the role and the time, one JSON line per event, append only. Keep out secrets, and hide private strings such as emails. And it must never raise: a log that cannot be written must not cost the user an answer (Day 112).

If you know another typed language (C# as the example): the allow-list is model validation with [RegularExpression] and a rule that rejects unknown properties (JsonUnmappedMemberHandling.Disallow), and the audit log is the structured log every API should keep for security events. Least privilege is the same principle as a database user with only db_datareader.
Capstone: on Saturday you add exactly this to ai-knowledge-assistant: the allow-list and the audit log, and show one blocked call with its log line.

4 · Worked example 5 min

What to give each part, and what to log:

least privilege: give every part ONLY what its job needs
  the user       a role: customer or staff (not 'everything')
  the tool       only the arguments it needs, only the values that fit
  the agent      only the tools of this task, a step limit, a budget for risky calls
  the database   a user that can read the chunks, not drop the table
  the key        a key for this service only, with a spending limit
what to put in an audit log                          what to leave out
who (the role), what (the event), when (UTC)           secrets, keys, passwords
every question, and what it was answered from           the text of the answer (it may hold private data)
every tool call: tool, arguments, outcome, reason       personal data you do not need (emails: hide them)
every block: what was blocked and why
rules: append only, never raises, one JSON line per event

import re
from typing import Any
from urllib.parse import urlparse

# An allow-list, not a deny-list: only what is written here is accepted. ASCII digits only ([0-9], not \d, which also matches other scripts).
ALLOWED_ARGUMENTS: dict[str, dict[str, re.Pattern[str]]] = {
    "lookup_error": {"code": re.compile(r"[Ee][0-9]{3}")},
    "close_incident": {"code": re.compile(r"[Ee][0-9]{3}")},
    "list_error_codes": {},
}
HINTS = {
    "lookup_error": "send only the argument 'code': the letter E and three digits, like E104",
    "close_incident": "send only the argument 'code': the letter E and three digits, like E104",
    "list_error_codes": "send no arguments",
}
INJECTION_PATTERNS = [
    re.compile(r"ignore\s+(all\s+)?(the\s+)?(previous|prior|above|earlier)\s+(instructions|rules|prompts?)", re.IGNORECASE),
    re.compile(r"disregard\s+(all\s+)?(the\s+)?(previous|prior|above|earlier|your)\s+(instructions|rules)", re.IGNORECASE),
    re.compile(r"(reveal|show|print)\s+(your\s+|the\s+)?system\s+prompt", re.IGNORECASE),
]
URL = re.compile(r"https?://[^\s)>\]\"']+", re.IGNORECASE)
ALLOWED_DOMAINS = ("pumpguard.example",)


def hint_for(name: str) -> str:
    return HINTS.get(name, "this tool has no argument policy")


def check_arguments(name: str, tool_input: dict[str, Any]) -> str | None:
    """Return a reason if the call must be blocked, or None. Unknown tools and unexpected arguments are blocked (fail closed)."""
    allowed = ALLOWED_ARGUMENTS.get(name)
    if allowed is None:
        return f"there is no argument policy for the tool {name!r}"
    unexpected = sorted(set(tool_input) - set(allowed))
    if unexpected:
        return f"the argument {unexpected[0]!r} is not allowed for {name}"
    for key, pattern in allowed.items():
        if key in tool_input and not (isinstance(tool_input[key], str) and pattern.fullmatch(tool_input[key])):
            return f"the argument {key!r} does not match the allow-list for {name}"
    return None


def check_output(text: str, allowed_domains: tuple[str, ...] = ALLOWED_DOMAINS) -> str | None:
    """Return a reason if an answer links to a site that is not on the allow-list. It only sees full http(s) links: a first layer, not a wall."""
    for link in URL.findall(text):
        host = (urlparse(link).hostname or "").lower()
        if not any(host == domain or host.endswith("." + domain) for domain in allowed_domains):
            return f"the answer links to {host or link!r}, which is not on the allow-list"
    return None


def scan_for_injection(text: str) -> str | None:
    """A weak, cheap check for text that talks TO the model instead of ABOUT the product. Easy to get around: use it to warn, never to trust."""
    for pattern in INJECTION_PATTERNS:
        found = pattern.search(text)
        if found:
            return f"looks like an instruction to the model: {found.group(0)!r}"
    return None

The audit log, in src/my_ai_project/audit.py. It replaces the question log of Day 112: one class for every event, with emails and key shapes hidden before anything is written:

import json
import logging
import re
from datetime import datetime, timezone
from pathlib import Path

logger = logging.getLogger("audit")

EMAIL = re.compile(r"[\w.+-]+@[\w-]+\.[\w.-]+")
KEY = re.compile(r"\b(?:sk|pk|key)-[A-Za-z0-9_-]{12,}")


def redact(value: object) -> object:
    """Hide the most common private strings (emails, API-key shapes) before anything is written. A safety net, not a guarantee."""
    if isinstance(value, str):
        return KEY.sub("[key]", EMAIL.sub("[email]", value))
    if isinstance(value, dict):
        return {k: redact(v) for k, v in value.items()}
    if isinstance(value, list):
        return [redact(v) for v in value]
    return value


class AuditLog:
    """An append-only record of what happened: every question, every tool call, and what was blocked. One JSON line per event."""

    def __init__(self, path: Path) -> None:
        self.path = path

    def record(self, event: str, role: str, **details: object) -> None:
        """Never raises: a log that cannot be written must not cost the user their answer."""
        line = {"time": datetime.now(timezone.utc).isoformat(), "event": event, "role": role, **{k: redact(v) for k, v in details.items()}}
        try:
            self.path.parent.mkdir(parents=True, exist_ok=True)
            with self.path.open("a", encoding="utf-8") as file:
                file.write(json.dumps(line) + "\n")
        except OSError as err:
            logger.warning("could not write the audit log %s: %s", self.path, err)

6 · Stuck? anytime

  • A good call is blocked: check the policy for the tool name and the pattern. Print the reason: it names the argument.
  • The log file does not appear: check the AUDIT_LOG path. The log never raises, so a path that cannot be written only gives a warning in the application log.
  • Tests write into logs/: the autouse fixture in tests/conftest.py must set AUDIT_LOG to a temporary folder.
  • mypy: the details of record: **details: object is enough.
Solution: Step 2

None of the eight results change, because they all fail or pass on code and the extra role. But a call with verbose now passes the allow-list, and nothing happens, because LookupInput and the function do not use it. The allow-list says what may arrive; the tool has to be changed to use it. Both places are written down on purpose, so that a new argument is a decision.

Solution: Step 3

The test for the digits from another script fails: E١٠٤ is accepted by \d. Change it back to [0-9].
