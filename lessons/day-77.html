Today you will be able to answer a question from your own knowledge base with cited sources through POST /api/ask, with tests that need no database, model or key.

1 · Warm-up 5 min

Answer from memory, then open the answers.

  1. Why can a high similarity still end in “not found”?
  2. What does hybrid search add to a vector search?
Answers
  1. The score says something similar exists, not that the answer is in it. The right page may not have been retrieved (E104 with a vector search alone).
  2. A keyword search that finds exact words, fused by rank, so a rare word like e104 can bring its page to the top.

2 · The goal 5 min

Today ai-knowledge-assistant gets its first real RAG pipeline. By the end:

  • answer_question takes a question and does it all: hybrid retrieval, a refusal when nothing is close, a grounded answer, and a check of the citations.
  • POST /api/ask returns the answer, whether it was refused and why, and the sources it cites.
  • An answer with no citation, or with an invented one, is never shown: it becomes a refusal with a reason.
  • The tests need no database, no model and no key.
  • The checkpoint of the module: five questions answered with sources.
Capstone: this is the Module 6 checkpoint of the capstone: the assistant answers from its own knowledge base and shows where each answer came from.
About the writer. In this lesson the answers come from a simulated writer (Day 72), because the lesson has no key. It is not a real model. The pipeline, the checks and the sources are real; the wording is not. To use a real model, set LLM_MODE=real and ANTHROPIC_API_KEY: your answers will be worded differently, and that is a good test of the checks.

4 · Build 90 min

Step 1: the pipeline

A new module src/my_ai_project/rag.py. The rule is simple: no source, no answer. Every way it can go wrong becomes a refusal with a reason a person can read:

from dataclasses import dataclass, field

from my_ai_project.embedder import Embedder
from my_ai_project.grounding import GroundedAnswer, Writer, ground
from my_ai_project.hybrid import KeywordIndex, hybrid_search
from my_ai_project.pipeline import Searcher
from my_ai_project.prompts import NO_ANSWER
from my_ai_project.store import Found


@dataclass
class RagAnswer:
    question: str
    text: str
    sources: list[Found] = field(default_factory=list)  # the chunks the answer cites
    refused: bool = False
    reason: str = ""


def refuse(question: str, reason: str) -> RagAnswer:
    return RagAnswer(question, NO_ANSWER, [], True, reason)


def answer_question(
    question: str,
    embedder: Embedder,
    store: Searcher,
    keywords: KeywordIndex,
    writer: Writer,
    top_k: int = 3,
    min_score: float = 0.6,
) -> RagAnswer:
    """Question -> retrieve -> answer with cited sources. No source, or no valid citation, means no answer."""
    found = hybrid_search(question, embedder, store, keywords, top_k=top_k)
    best = max((f.similarity for f in found), default=0.0)
    if best < min_score:
        return refuse(question, f"best similarity {best:.2f} is under {min_score}")
    grounded: GroundedAnswer = ground(question, found, writer)
    if grounded.refused:
        return refuse(question, "the writer found no answer in the sources")
    if grounded.invented:
        return refuse(question, f"the answer cited {grounded.invented[0]}, which was not retrieved")
    if not grounded.sources:
        return refuse(question, "the answer cited no source")
    return RagAnswer(question, grounded.text, grounded.sources)

Step 2: dependencies

In deps.py. The keyword index is built once from the stored chunks (restart the API after a new ingest). The writer is simulated unless LLM_MODE=real:

@lru_cache
def get_keywords() -> KeywordIndex:
    """The keyword index is built once from the stored chunks. Restart the API after a new ingest."""
    try:
        return KeywordIndex(ChunkStore(os.environ.get("DATABASE_URL", "postgresql://assistant:assistant@localhost:5433/assistant")).all_chunks())
    except psycopg.OperationalError as err:
        raise HTTPException(status_code=503, detail="the database is not available") from err


def get_writer() -> Writer:
    if os.environ.get("LLM_MODE", "fake") == "real":
        api_key = os.environ.get("ANTHROPIC_API_KEY")
        if not api_key:
            raise RuntimeError("LLM_MODE is real, but ANTHROPIC_API_KEY is not set")
        return RetryingClient(AnthropicClient(api_key=api_key, timeout=30.0), max_attempts=3)
    return SimulatedWriter()   # NOT a real model: it lets you run and test the pipeline with no key


KeywordsDep = Annotated[KeywordIndex, Depends(get_keywords)]
WriterDep = Annotated[Writer, Depends(get_writer)]

Step 3: the endpoint

Add these to api.py (and import KeywordsDep, WriterDep and answer_question). It reuses the SearchHit model of Day 70 for the sources:

class AskRequest(BaseModel):
    question: str = Field(min_length=1, max_length=500)
    top_k: int = Field(default=3, ge=1, le=10)


class AskResponse(BaseModel):
    question: str
    answer: str
    refused: bool
    reason: str
    sources: list[SearchHit]


@app.post("/api/ask")
def ask(request: AskRequest, embedder: EmbedderDep, store: StoreDep, keywords: KeywordsDep, writer: WriterDep) -> AskResponse:
    try:
        result = answer_question(request.question, embedder, store, keywords, writer, top_k=request.top_k)
    except psycopg.OperationalError as err:
        raise HTTPException(status_code=503, detail="the database is not available") from err
    sources = [
        SearchHit(citation=f.citation, doc_id=f.doc_id, chunk_index=f.chunk_index, title=f.title, kind=f.kind, text=f.text, similarity=f.similarity)
        for f in result.sources
    ]
    return AskResponse(question=request.question, answer=result.text, refused=result.refused, reason=result.reason, sources=sources)

Step 4: tests

The tests replace all four dependencies, so they run in milliseconds. Notice the test with the careless writer: an invented citation must never reach the user.

from collections.abc import Iterator

import numpy as np
import psycopg
import pytest
from fastapi.testclient import TestClient

from my_ai_project.api import app
from my_ai_project.deps import get_embedder, get_keywords, get_store, get_writer
from my_ai_project.embedder import FakeEmbedder
from my_ai_project.hybrid import KeywordIndex
from my_ai_project.retrieval import normalize
from my_ai_project.simulated import SimulatedWriter
from my_ai_project.store import Found

CHUNKS = [
    Found("error-e101", 0, "E101 Sensor timeout", "error", "The sensor did not answer. Check the sensor cable and restart the monitor.", 0.0),
    Found("faq-battery", 0, "Battery life", "faq", "The battery lasts about eight hours. Charge it every night.", 0.0),
    Found("manual-install", 0, "Installation guide", "manual", "Mount the sensor on a flat wall. Connect the cable.", 0.0),
]


class InMemoryStore:
    """The same search as the database store, in memory, so the API tests need no database."""

    def __init__(self) -> None:
        self.vectors = normalize(FakeEmbedder().embed([f"{c.title}. {c.text}" for c in CHUNKS]))

    def search(self, query_vector: np.ndarray, top_k: int = 3, kind: str | None = None) -> list[Found]:
        scores = self.vectors @ (query_vector / np.linalg.norm(query_vector))
        order = scores.argsort()[::-1][:top_k]
        return [Found(CHUNKS[i].doc_id, CHUNKS[i].chunk_index, CHUNKS[i].title, CHUNKS[i].kind, CHUNKS[i].text, round(float(scores[i]), 2)) for i in order]


class BrokenStore:
    def search(self, query_vector: np.ndarray, top_k: int = 3, kind: str | None = None) -> list[Found]:
        raise psycopg.OperationalError("connection refused")


@pytest.fixture
def client() -> Iterator[TestClient]:
    app.dependency_overrides[get_embedder] = FakeEmbedder
    app.dependency_overrides[get_store] = InMemoryStore
    app.dependency_overrides[get_keywords] = lambda: KeywordIndex(CHUNKS)
    app.dependency_overrides[get_writer] = SimulatedWriter
    yield TestClient(app)
    app.dependency_overrides.clear()


def test_an_answer_comes_with_its_source(client: TestClient) -> None:
    body = client.post("/api/ask", json={"question": "Is it true that the battery lasts about eight hours?"}).json()
    assert body["refused"] is False
    assert body["answer"].endswith("[faq-battery#0].")
    assert [s["citation"] for s in body["sources"]] == ["[faq-battery#0]"]


def test_no_source_means_a_refusal(client: TestClient) -> None:
    body = client.post("/api/ask", json={"question": "Where can I buy a coffee?"}).json()
    assert body["refused"] is True
    assert body["answer"] == "I could not find that in the knowledge base."
    assert body["sources"] == []
    assert "under 0.6" in body["reason"]


def test_an_invented_citation_is_not_shown(client: TestClient) -> None:
    app.dependency_overrides[get_writer] = lambda: SimulatedWriter(careless=True)
    body = client.post("/api/ask", json={"question": "Is it true that the battery lasts about eight hours?"}).json()
    assert body["refused"] is True
    assert "faq-support#0" in body["reason"]


@pytest.mark.parametrize("payload", [{"question": ""}, {"question": "x", "top_k": 0}, {"question": "x", "top_k": 11}, {}])
def test_bad_requests_are_a_422(client: TestClient, payload: dict[str, object]) -> None:
    assert client.post("/api/ask", json=payload).status_code == 422


def test_a_database_that_is_down_is_a_503(client: TestClient) -> None:
    app.dependency_overrides[get_store] = BrokenStore
    response = client.post("/api/ask", json={"question": "Is it true that the battery lasts about eight hours?"})
    assert response.status_code == 503
    assert response.json() == {"detail": "the database is not available"}

Step 5: the checkpoint

Write a script that asks your five questions and prints the answer and the sources. Use the five below, or your own (keep at least one that should be refused). ask_five.py:

import os

from my_ai_project.embedder import FastEmbedder
from my_ai_project.hybrid import KeywordIndex
from my_ai_project.rag import answer_question
from my_ai_project.simulated import SimulatedWriter
from my_ai_project.store import ChunkStore

QUESTIONS = [
    "How often should I calibrate the sensor?",
    "What does error E104 mean?",
    "Which Wi-Fi band does the monitor support?",
    "Where can I buy a coffee?",
    "How much does the monitor cost?",
]

store = ChunkStore(os.environ.get("DATABASE_URL", "postgresql://assistant:assistant@localhost:5433/assistant"))
embedder = FastEmbedder()
keywords = KeywordIndex(store.all_chunks())
writer = SimulatedWriter()   # NOT a real model: set up a real one in the API with LLM_MODE=real

for number, question in enumerate(QUESTIONS, start=1):
    result = answer_question(question, embedder, store, keywords, writer)
    sources = ", ".join(s.citation for s in result.sources) or "no source"
    print(f"{number}. {question}")
    print(f"   {result.text}")
    print(f"   sources: {sources}" + (f"   (refused: {result.reason})" if result.refused else ""))

6 · Stuck? anytime

  • Everything is refused: check the best similarity in the reason. If your questions are good and the scores are under 0.6, look at your chunks; do not lower the number until you have read the chunks.
  • A refusal with “cited no source”: the writer did not follow rule 3 of the prompt. Keep the rules exactly as in grounding.py.
  • The first request is slow: the model and the keyword index load once.
  • Tests try to reach the database: one of the four overrides is missing.

  1. Name four ways an answer can become a refusal in answer_question.
  2. Why does the gate use the best similarity of the whole list?
  3. What would make you trust an answer from this API more than from a plain model call?
Answers
  1. The best similarity is under the minimum; the writer says it found no answer; the answer cites a source that was not retrieved; the answer cites no source.
  2. After fusion, the first chunk may come from the keyword list only and have a similarity of 0.0. The best of the list says whether something close exists.
  3. It comes with sources you can open, the citations were checked by code, and it says “not found” instead of guessing.
