Project Lab 13: the tool-calling loop

Today you will be able to build a tool-calling loop that runs tools as the caller's role, stops after a limit, and shows the calls it made, with tests that need no model and no key.

1 · Warm-up 5 min

Answer from memory, then open the answers.

  1. Why does the role of the user decide what a tool may do, and not the model’s input?
  2. What does a good tool error have besides a message?
Answers
  1. The model chooses the input, so it could choose a role. The role comes from your code, from the login of the person who asked.
  2. A stable code and a hint for the next step.

2 · The goal 5 min

This is the first half of the Module 7 checkpoint: one real tool, with a simple loop. By the end:

  • assist() is a tool-calling loop: it asks the model, runs the tools the model asks for as the caller’s role, sends the results back, and stops at a final answer or after three rounds.
  • One adapter for a real model (AnthropicToolModel) and one stand-in (PretendToolModel) so everything runs without a key.
  • POST /api/assist returns the answer, the tool calls that were made, and the number of rounds.
  • Tests that need no model and no key, including a model that never stops asking.
Capstone: your assistant can now do two things: answer from documents (/api/ask) and look things up with a tool (/api/assist). In week 14 the React chat UI will use the tool through the .NET API.
About the model. The run in this lesson used PretendToolModel: it asks for lookup_error when the question contains something like E104, and writes its answer from the tool result. It is not a real model. The adapter for a real model was tested with the real SDK against a mock server, never against a real model, so the wording and the choices of a real model will be different. The loop, the roles, the errors and the limits are the real part. Try your own key when you can, and read what it does.

4 · Build 90 min

Step 1: the loop and the adapters

A new module src/my_ai_project/tool_loop.py. Notice three decisions: the replies are plain dicts (so the loop does not depend on SDK classes), the role goes into every execute, and the loop has a maximum number of rounds, because a model that keeps asking would otherwise run forever and cost money:

import json
import re
from dataclasses import dataclass, field
from typing import Any, Protocol

import anthropic

from my_ai_project.tool_design import LOOKUP_TOOL, execute

SYSTEM = (
    "You are a support assistant for the PumpGuard monitor. "
    "When the user asks about an error code, use the lookup_error tool, then answer from its result in at most two short sentences. "
    "If the tool returns an error, explain it plainly and do not guess."
)
GIVE_UP = "I could not finish that. Please try again or ask support."


@dataclass
class ToolReply:
    stop_reason: str
    content: list[dict[str, Any]]   # plain dicts: {"type": "text", ...} or {"type": "tool_use", ...}


class ToolModel(Protocol):
    def create(self, messages: list[dict[str, Any]], tools: list[dict[str, Any]], system: str) -> ToolReply: ...


@dataclass
class ToolCall:
    name: str
    tool_input: dict[str, Any]
    is_error: bool


@dataclass
class AssistResult:
    answer: str
    tool_calls: list[ToolCall] = field(default_factory=list)
    rounds: int = 0
    gave_up: bool = False


def text_of(reply: ToolReply) -> str:
    return " ".join(block["text"] for block in reply.content if block["type"] == "text").strip()


def assist(question: str, model: ToolModel, role: str, max_rounds: int = 3) -> AssistResult:
    """The tool loop: ask the model, run the tools it asks for as this user's role, send the results back, stop at a final answer."""
    messages: list[dict[str, Any]] = [{"role": "user", "content": question}]
    calls: list[ToolCall] = []
    for round_number in range(1, max_rounds + 1):
        reply = model.create(messages, [LOOKUP_TOOL], SYSTEM)
        if reply.stop_reason != "tool_use":
            return AssistResult(text_of(reply), calls, round_number)
        results = []
        for block in reply.content:
            if block["type"] == "tool_use":
                result = execute(block["id"], block["name"], block["input"], role)
                calls.append(ToolCall(block["name"], block["input"], bool(result.get("is_error"))))
                results.append(result)
        messages.append({"role": "assistant", "content": reply.content})
        messages.append({"role": "user", "content": results})
    return AssistResult(GIVE_UP, calls, max_rounds, gave_up=True)   # the model kept asking: do not loop forever


class AnthropicToolModel:
    """The real model. The SDK's blocks are turned into small plain dicts, so the rest of the code never depends on SDK classes."""

    def __init__(self, client: anthropic.Anthropic, model: str = "claude-haiku-4-5-20251001", max_tokens: int = 400) -> None:
        self.client, self.model, self.max_tokens = client, model, max_tokens

    def create(self, messages: list[dict[str, Any]], tools: list[dict[str, Any]], system: str) -> ToolReply:
        message = self.client.messages.create(model=self.model, max_tokens=self.max_tokens, system=system, tools=tools, messages=messages)  # type: ignore[arg-type]
        blocks: list[dict[str, Any]] = []
        for block in message.content:
            if block.type == "text":
                blocks.append({"type": "text", "text": block.text})
            elif block.type == "tool_use":
                blocks.append({"type": "tool_use", "id": block.id, "name": block.name, "input": dict(block.input)})  # type: ignore[arg-type]
        return ToolReply(message.stop_reason or "end_turn", blocks)


class PretendToolModel:
    """A stand-in for a model, to run the loop with no key and no cost. It is NOT a real model.

    It asks for lookup_error when the question contains something like E104, and it writes its answer from the tool result."""

    def create(self, messages: list[dict[str, Any]], tools: list[dict[str, Any]], system: str) -> ToolReply:
        last = messages[-1]["content"]
        if isinstance(last, str):
            found = re.search(r"\b[Ee]\d{3}\b", last)
            if not found:
                return ToolReply("end_turn", [{"type": "text", "text": "I can only look up error codes, like E104."}])
            return ToolReply("tool_use", [{"type": "tool_use", "id": "toolu_pretend", "name": "lookup_error", "input": {"code": found.group(0)}}])
        result = json.loads(last[0]["content"])
        if last[0].get("is_error"):
            error = result["error"]
            return ToolReply("end_turn", [{"type": "text", "text": f"I could not look that up: {error['message']}. {error.get('hint', '')}".strip()}])
        return ToolReply("end_turn", [{"type": "text", "text": f"{result['code']} means {result['name']} (severity {result['severity']}). {result['action']}"}])

Step 2: the dependency and the endpoint

In deps.py (add import anthropic too):

def get_tool_model() -> ToolModel:
    if os.environ.get("LLM_MODE", "fake") == "real":
        api_key = os.environ.get("ANTHROPIC_API_KEY")
        if not api_key:
            raise RuntimeError("LLM_MODE is real, but ANTHROPIC_API_KEY is not set")
        return AnthropicToolModel(anthropic.Anthropic(api_key=api_key, timeout=30.0))
    return PretendToolModel()   # NOT a real model: it lets you run and test the loop with no key


ToolModelDep = Annotated[ToolModel, Depends(get_tool_model)]

In api.py (import assist and ToolModelDep). A failure of the model API becomes a 502:

class AssistRequest(BaseModel):
    question: str = Field(min_length=1, max_length=500)


class ToolCallInfo(BaseModel):
    name: str
    tool_input: dict[str, Any]
    is_error: bool


class AssistResponse(BaseModel):
    answer: str
    tool_calls: list[ToolCallInfo]
    rounds: int
    gave_up: bool


@app.post("/api/assist")
def assist_with_tools(request: AssistRequest, model: ToolModelDep, role: RoleDep) -> AssistResponse:
    try:
        result = assist(request.question, model, role)
    except anthropic.APIError as err:
        raise HTTPException(status_code=502, detail="the model call failed") from err
    calls = [ToolCallInfo(name=c.name, tool_input=c.tool_input, is_error=c.is_error) for c in result.tool_calls]
    return AssistResponse(answer=result.answer, tool_calls=calls, rounds=result.rounds, gave_up=result.gave_up)

Step 3: tests

The scripted model replays a list of replies and remembers what it was sent, so you can check exactly what the loop sends back after a tool call. One test uses the real SDK against a mock server to check the adapter:

import json
from typing import Any

import anthropic
import httpx2
from fastapi.testclient import TestClient

from my_ai_project.api import app
from my_ai_project.deps import get_tool_model
from my_ai_project.tool_loop import GIVE_UP, AnthropicToolModel, PretendToolModel, ToolReply, assist


class Scripted:
    """A model that replays a list of replies and remembers what it was sent."""

    def __init__(self, replies: list[ToolReply]) -> None:
        self.replies = replies
        self.seen: list[list[dict[str, Any]]] = []

    def create(self, messages: list[dict[str, Any]], tools: list[dict[str, Any]], system: str) -> ToolReply:
        self.seen.append(json.loads(json.dumps(messages)))
        return self.replies.pop(0)


def ask_for(code: str) -> ToolReply:
    return ToolReply("tool_use", [{"type": "tool_use", "id": "toolu_1", "name": "lookup_error", "input": {"code": code}}])


def say(text: str) -> ToolReply:
    return ToolReply("end_turn", [{"type": "text", "text": text}])


def test_the_loop_runs_the_tool_and_returns_the_final_answer() -> None:
    model = Scripted([ask_for("E104"), say("E104 means Disk full.")])
    result = assist("What is E104?", model, "staff")
    assert result.answer == "E104 means Disk full."
    assert [(c.name, c.is_error) for c in result.tool_calls] == [("lookup_error", False)]
    assert result.rounds == 2
    sent = model.seen[1][-1]["content"][0]
    assert sent["type"] == "tool_result" and sent["tool_use_id"] == "toolu_1"


def test_the_users_role_decides_what_the_tool_may_do() -> None:
    model = Scripted([ask_for("E104"), say("Please ask support staff.")])
    result = assist("What is E104?", model, "customer")
    assert result.tool_calls[0].is_error is True
    assert "permission_denied" in model.seen[1][-1]["content"][0]["content"]


def test_a_model_that_never_stops_asking_is_stopped() -> None:
    model = Scripted([ask_for("E104")] * 5)
    result = assist("What is E104?", model, "staff", max_rounds=3)
    assert result.gave_up and result.answer == GIVE_UP and result.rounds == 3
    assert len(model.seen) == 3


def test_a_question_without_a_tool_call_is_one_round() -> None:
    result = assist("Hello", Scripted([say("Hi.")]), "customer")
    assert result.tool_calls == [] and result.rounds == 1


def test_the_pretend_model_answers_from_the_tool_result() -> None:
    result = assist("What does error E104 mean?", PretendToolModel(), "staff")
    assert result.answer.startswith("E104 means Disk full (severity high).")


def test_the_real_adapter_sends_tools_and_reads_tool_use_blocks() -> None:
    sent: list[dict[str, Any]] = []

    def handler(request: httpx2.Request) -> httpx2.Response:
        body = json.loads(request.content)
        sent.append(body)
        block = {"type": "tool_use", "id": "toolu_x", "name": "lookup_error", "input": {"code": "E104"}}
        reply = {"id": "msg_1", "type": "message", "role": "assistant", "model": body["model"], "content": [block],
                 "stop_reason": "tool_use", "stop_sequence": None, "usage": {"input_tokens": 10, "output_tokens": 5}}
        return httpx2.Response(200, json=reply)

    client = anthropic.Anthropic(api_key="not-a-real-key", http_client=httpx2.Client(transport=httpx2.MockTransport(handler)))
    reply = AnthropicToolModel(client).create([{"role": "user", "content": "E104?"}], [{"name": "lookup_error", "description": "d", "input_schema": {"type": "object"}}], "be brief")
    assert sent[0]["system"] == "be brief" and sent[0]["tools"][0]["name"] == "lookup_error"
    assert reply.stop_reason == "tool_use" and reply.content[0]["input"] == {"code": "E104"}


def test_the_endpoint_returns_the_answer_and_the_calls() -> None:
    app.dependency_overrides[get_tool_model] = PretendToolModel
    try:
        client = TestClient(app)
        staff = client.post("/api/assist", json={"question": "What does error E104 mean?"}, headers={"x-demo-role": "staff"}).json()
        customer = client.post("/api/assist", json={"question": "What does error E104 mean?"}).json()
        assert staff["tool_calls"] == [{"name": "lookup_error", "tool_input": {"code": "E104"}, "is_error": False}]
        assert "Disk full" in staff["answer"]
        assert customer["tool_calls"][0]["is_error"] is True and "Disk full" not in customer["answer"]
        assert client.post("/api/assist", json={"question": ""}).status_code == 422
    finally:
        app.dependency_overrides.clear()

6 · Stuck? anytime

  • The SDK says the message format is wrong: after a tool_use, the next user message must hold a tool_result for every tool_use id. Check that you add the assistant message and the results.
  • The loop returns the give-up text: the model kept asking. Print the tool calls; a tool that always returns an error can make a model retry.
  • mypy complains about SDK types: the two type: ignore comments are in the adapter on purpose; keep them out of the rest of the code.
  • A customer gets the record: the endpoint must pass the role to assist, and assist to execute.
  • You want to try a real model: set LLM_MODE=real and ANTHROPIC_API_KEY. Watch the tool_calls and rounds of the answers; they will differ from this lesson.

8 · Check yourself 5 min

  1. Why does the loop have a maximum number of rounds?
  2. Why are the replies plain dicts and not SDK objects?
  3. What does the number of rounds tell you?
Answers
  1. A model that keeps asking for tools would run forever and cost money. A limit turns that into a clear give-up answer.
  2. The rest of the code and the tests do not depend on the SDK, and you can swap the model, or fake it, easily.
  3. How many times the model was called: 1 means no tool was needed, 2 means one tool call and an answer. A high number is a warning.
