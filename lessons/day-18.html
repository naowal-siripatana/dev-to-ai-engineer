2 · Hook 2 min

A colleague sends you a table of error codes. Some codes are lower case, some have spaces around them, one is missing, and one appears twice. If your assistant reads it as it is, which answers go wrong?

Guess first, then open

Almost all of them. e102 and E102 are different words to a computer, a code with a space does not match, and the double entry may show up twice in an answer. A model is only as good as the data you give it, and today you clean a small table before anyone uses it.

3 · The idea, in three small pieces 8 min

Piece 1: a DataFrame is a table in memory

pandas is the Python library for tables. pd.read_csv("file.csv") reads a file and gives you a DataFrame: rows, columns, and a name for each column. You pick a column with table["code"].

Piece 2: one line cleans a whole column

You do not write a loop. table["code"].str.strip().str.upper() cleans every row at once: .str.strip() removes spaces at the ends, .str.upper() makes capitals. .fillna("...") fills empty cells, .dropna() removes rows with empty cells, .drop_duplicates() removes repeated rows.

Piece 3: look before and after

Never clean blind. First look: .shape (rows and columns), .head(3) (the first rows), .isna().sum() (how many empty cells per column), .value_counts() (how many times each value appears). Then clean, then look again.

If you know another typed language (C# as the example): a DataFrame is like a DataTable, or a List<T> that you query with LINQ. table[table["severity"] == "high"] is Where(x => x.Severity == "high"), and .str.strip() is a Select with Trim() on each row. In pandas you work on the whole column, not row by row.
Capstone: the knowledge base of the assistant is made of tables and documents like this one. Clean data is the cheapest way to get better answers, long before any model is involved.

Look at the header: the second column is called ' Title ', with spaces. code has 1 empty cell and Description has 1. Now the cleaning function. src/my_ai_project/error_codes.py:

from pathlib import Path

import pandas as pd


def load_error_codes(path: Path) -> pd.DataFrame:
    table = pd.read_csv(path)
    table.columns = [name.strip().lower() for name in table.columns]
    table["code"] = table["code"].str.strip().str.upper()
    table["title"] = table["title"].str.strip()
    table["severity"] = table["severity"].str.strip().str.lower()
    table["description"] = table["description"].fillna("No description")
    table = table.dropna(subset=["code"])
    table = table.drop_duplicates(subset=["code"])
    return table.reset_index(drop=True)

6 · Stuck? anytime

  • “FileNotFoundError: No such file or directory”: the path is relative to the folder you run from. Run from the project folder, and check that the file is data/error_codes.csv.
  • “KeyError: 'title'”: the columns were not cleaned yet. Clean the column names first (table.columns = [...]), then use the new names. Print list(table.columns) to see the real names.
  • “Can only use .str accessor with string values”: the column has no text (for example it is all empty). Check the CSV and the column name.
  • Your table prints differently from the lesson: widths and the dtype names can differ by pandas version. Compare the rows, not the spacing.
  • “ModuleNotFoundError: No module named 'pandas'”: run uv add pandas, and run scripts with uv run.
Hint: Step 4

Two steps: first a row filter, table[table["severity"] == "high"], which keeps only the rows where the condition is true. Then choose the columns with a list inside the brackets: [["code", "title"]] (two pairs of brackets).

7 · Check yourself 5 min

  1. What is a DataFrame, and what does .str.strip().str.upper() do to it?
  2. Why do you look at shape, head and isna().sum() before you clean?
  3. The table had 6 rows and ended with 4. Where did two rows go?
Answers
  1. A table in memory with rows and named columns. The two calls remove the spaces at the ends of every value in the column and turn every value into capitals, in one line and without a loop.
  2. To see what is wrong, so you clean the real problems and not imaginary ones. Cleaning blind can also hide a problem, for example by dropping rows you did not mean to drop.
  3. One row had no code (dropna on code removed it), and one code appeared twice (drop_duplicates kept the first).
