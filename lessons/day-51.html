Timeouts, retries and rate limits

  2. Which errors does your structured helper retry, and what does it send in the retry?

2 · Hook 2 min

The model provider is overloaded for three seconds. Your app, like thousands of others, retries each failed call at once, again and again. What do you think happens to the provider, and to your users?

Guess first, then open

The extra calls make the overload worse and last longer, so everyone fails for longer. This is called a retry storm. The fix is to retry politely: wait a little, wait longer each time, add some randomness so not everyone comes back at the same moment, and stop after a few tries. Today you build exactly that.

3 · The idea, in three small pieces 8 min

Piece 1: never wait forever

A timeout is the longest you are willing to wait. Without one, a stuck call can hold your user for minutes. The SDK’s default read timeout is 600 seconds (ten minutes), which is far too long for a chat, so you set your own (for example 30 seconds) in the client. A timeout is an error like any other: you decide what to do next.

Piece 2: retry only what may go away, and wait longer each time

Some failures are temporary: a timeout, a lost connection, a busy provider (429 too many requests, 5xx server errors). Waiting and trying again can help. Others will never change: a wrong key (401), a bad request (400), a missing model (404). Retrying those only wastes time. For the temporary ones use exponential backoff: wait about 0.5 s, then 1 s, then 2 s, with a ceiling. Add jitter (a random part), so a thousand clients do not all come back at the same instant. If the provider sends a Retry-After header, wait that long. Stop after a few attempts.

Piece 3: a rate limit is a request to slow down

A rate limit caps how many requests or tokens you may use per minute. When you pass it you get 429. Retrying politely is the first answer. The better answers are to use fewer tokens (Day 32 to Day 35), to avoid repeated identical calls, and, in a bigger system, to put work in a queue. One more rule: a stream can be retried only before its first piece. After a piece has gone to the user, a retry would repeat or mix the text.

If you know another typed language (C# as the example): this is a Polly policy: WaitAndRetryAsync with exponential backoff and jitter, HandleResult for the retryable status codes, and a timeout policy around it. HttpClient.Timeout is the timeout.
Capstone: your assistant depends on a service that you do not control. Timeouts, polite retries and a clear error at the end are what make it feel dependable instead of flaky. Saturday you combine this with a better prompt.

4 · Worked example 5 min

Read it first. Two small changes. First, the client tells temporary failures from permanent ones: RetryableLlmError carries an optional retry_after, is_retryable decides by status code (more reliable than a list of exception classes: this SDK has several different classes for busy and overloaded errors), and the client gets a timeout and turns off the SDK’s own retries (max_retries=0), so only your code retries. src/my_ai_project/llm.py:

import logging
import time
from collections.abc import Iterator
from typing import Protocol

import anthropic

logger = logging.getLogger("llm")

CHAT_REPLY = '{"answer": "Check the sensor cable and restart.", "sources": ["error-e101"], "confidence": "medium"}'
EXTRACT_REPLY = '{"error_code": "E101", "severity": "medium", "action": "Check the sensor cable"}'


class LlmError(Exception):
    """Raised when a model call fails."""


class RetryableLlmError(LlmError):
    """A failure that may go away if we wait and try again: a timeout, a rate limit, a busy server."""

    def __init__(self, message: str, retry_after: float | None = None) -> None:
        super().__init__(message)
        self.retry_after = retry_after


RETRYABLE_STATUS = {408, 409, 429}


def is_retryable(err: anthropic.APIError) -> bool:
    """Timeouts, lost connections, rate limits and server-side errors may go away. A wrong key or a bad request will not."""
    if isinstance(err, anthropic.APIStatusError):
        return err.status_code in RETRYABLE_STATUS or err.status_code >= 500
    return isinstance(err, anthropic.APIConnectionError)  # includes timeouts


def to_llm_error(err: anthropic.APIError, model: str) -> LlmError:
    if is_retryable(err):
        retry_after = None
        if isinstance(err, anthropic.APIStatusError) and "retry-after" in err.response.headers:
            try:
                retry_after = float(err.response.headers["retry-after"])
            except ValueError:
                retry_after = None
        logger.warning("llm call failed model=%s error=%s (can retry)", model, type(err).__name__)
        return RetryableLlmError("the model call failed", retry_after=retry_after)
    logger.error("llm call failed model=%s error=%s", model, type(err).__name__)
    return LlmError("the model call failed")


class StreamingClient(Protocol):
    def complete(self, prompt: str) -> str: ...

    def stream(self, prompt: str) -> Iterator[str]: ...


class FakeLlmClient:
    """Stands in for the real model: no network, no cost, same answer every time."""

    def __init__(self, reply: str | None = None, fail_after: int | None = None) -> None:
        self.reply = reply
        self.fail_after = fail_after

    def complete(self, prompt: str) -> str:
        if self.reply is not None:
            return self.reply
        if prompt.startswith("Extract"):
            return EXTRACT_REPLY
        if prompt.startswith("Answer briefly") and "JSON Schema" in prompt:
            return CHAT_REPLY
        prompt = prompt.removeprefix("Summarize in one sentence: ")
        return "(fake) " + prompt.removeprefix("Answer briefly: ")

    def stream(self, prompt: str) -> Iterator[str]:
        for number, word in enumerate(self.complete(prompt).split(" ")):
            if self.fail_after is not None and number >= self.fail_after:
                raise LlmError("the model call failed")
            yield word + " "


class AnthropicClient:
    def __init__(
        self,
        api_key: str,
        model: str = "claude-haiku-4-5-20251001",
        max_tokens: int = 300,
        timeout: float = 30.0,
        http_client: anthropic.DefaultHttpxClient | None = None,
    ) -> None:
        # max_retries=0: our own RetryingClient decides when to retry, so the SDK does not retry a second time behind our back.
        self.client = anthropic.Anthropic(api_key=api_key, timeout=timeout, max_retries=0, http_client=http_client)
        self.model = model
        self.max_tokens = max_tokens

    def complete(self, prompt: str) -> str:
        started = time.perf_counter()
        try:
            message = self.client.messages.create(
                model=self.model,
                max_tokens=self.max_tokens,
                messages=[{"role": "user", "content": prompt}],
            )
        except anthropic.APIError as err:
            raise to_llm_error(err, self.model) from err
        text = "".join(block.text for block in message.content if block.type == "text")
        logger.info(
            "llm call ok model=%s prompt_chars=%d reply_chars=%d input_tokens=%d output_tokens=%d ms=%d",
            self.model,
            len(prompt),
            len(text),
            message.usage.input_tokens,
            message.usage.output_tokens,
            round((time.perf_counter() - started) * 1000),
        )
        return text

    def stream(self, prompt: str) -> Iterator[str]:
        started = time.perf_counter()
        pieces = 0
        try:
            with self.client.messages.stream(
                model=self.model,
                max_tokens=self.max_tokens,
                messages=[{"role": "user", "content": prompt}],
            ) as stream:
                for text in stream.text_stream:
                    pieces += 1
                    yield text
                final = stream.get_final_message()
        except anthropic.APIError as err:
            raise to_llm_error(err, self.model) from err
        logger.info(
            "llm stream ok model=%s prompt_chars=%d pieces=%d input_tokens=%d output_tokens=%d ms=%d",
            self.model,
            len(prompt),
            pieces,
            final.usage.input_tokens,
            final.usage.output_tokens,
            round((time.perf_counter() - started) * 1000),
        )

Second, a wrapper that retries, with backoff, jitter, Retry-After, a ceiling, and the stream rule. src/my_ai_project/retry.py:

import logging
import random
import time
from collections.abc import Callable, Iterator

from my_ai_project.llm import RetryableLlmError, StreamingClient

logger = logging.getLogger("retry")


class RetryingClient:
    """Wraps a client and retries failures that may go away: wait a little longer each time, with a random jitter."""

    def __init__(
        self,
        inner: StreamingClient,
        max_attempts: int = 3,
        base_delay: float = 0.5,
        max_delay: float = 8.0,
        sleep: Callable[[float], None] = time.sleep,
        rng: random.Random | None = None,
    ) -> None:
        self.inner = inner
        self.max_attempts = max_attempts
        self.base_delay = base_delay
        self.max_delay = max_delay
        self.sleep = sleep
        self.rng = rng or random.Random()

    def _delay(self, attempt: int, retry_after: float | None) -> float:
        if retry_after is not None:
            return min(retry_after, self.max_delay)
        ceiling = min(self.max_delay, self.base_delay * 2 ** (attempt - 1))
        return self.rng.uniform(0, ceiling)

    def _wait_or_raise(self, attempt: int, err: RetryableLlmError) -> None:
        if attempt == self.max_attempts:
            logger.error("giving up after %d attempts", attempt)
            raise err
        delay = self._delay(attempt, err.retry_after)
        logger.warning("retry %d of %d in %.2fs", attempt, self.max_attempts - 1, delay)
        self.sleep(delay)

    def complete(self, prompt: str) -> str:
        attempt = 1
        while True:
            try:
                return self.inner.complete(prompt)
            except RetryableLlmError as err:
                self._wait_or_raise(attempt, err)
                attempt += 1

    def stream(self, prompt: str) -> Iterator[str]:
        attempt = 1
        while True:
            started = False
            try:
                for piece in self.inner.stream(prompt):
                    started = True
                    yield piece
                return
            except RetryableLlmError as err:
                if started:
                    raise  # pieces were already sent: retrying would repeat or mix text
                self._wait_or_raise(attempt, err)
                attempt += 1

6 · Stuck? anytime

  • The demo never prints waits: the demo passes sleep=waits.append, so it records instead of sleeping. In your real app the default is time.sleep.
  • The same error is retried twice as often as you expect: the SDK retries by itself unless you pass max_retries=0. Do it, so there is one place that decides.
  • mypy: the fake client does not match the protocol: the fake needs both methods, complete(self, prompt) and stream(self, prompt), with the same arguments as the real client.
  • A 529 is not retried: decide by status code (>= 500), not by the exception class.
  • Your test takes seconds: you used the real time.sleep. Pass sleep=waits.append.
Hint: Step 4

A fake client is a class with a list of errors and a counter. Each call raises the next error until the list is empty, then returns a reply. To see exact waits, make a subclass of random.Random whose uniform(a, b) returns b: with base_delay=0.5 the waits are 0.5, 1.0, 2.0, 4.0, then the ceiling.

Solution: Step 4 (tests)
import random
from collections.abc import Iterator

import httpx2
import pytest

from my_ai_project.llm import AnthropicClient, LlmError, RetryableLlmError
from my_ai_project.retry import RetryingClient


class TopRng(random.Random):
    """Always picks the top of the range, so the delays are easy to read in a test."""

    def uniform(self, a: float, b: float) -> float:
        return b


class FlakyClient:
    def __init__(self, failures: list[LlmError], reply: str = "ok") -> None:
        self.failures = failures
        self.reply = reply
        self.calls = 0

    def complete(self, prompt: str) -> str:
        self.calls += 1
        if self.failures:
            raise self.failures.pop(0)
        return self.reply

    def stream(self, prompt: str) -> Iterator[str]:
        self.calls += 1
        if self.failures:
            raise self.failures.pop(0)
        yield from self.reply.split()


def make(inner: FlakyClient, waits: list[float], max_attempts: int = 3) -> RetryingClient:
    return RetryingClient(inner, max_attempts=max_attempts, base_delay=0.5, max_delay=8.0, sleep=waits.append, rng=TopRng())


def test_it_retries_and_waits_longer_each_time() -> None:
    inner = FlakyClient([RetryableLlmError("busy"), RetryableLlmError("busy")])
    waits: list[float] = []
    assert make(inner, waits).complete("hi") == "ok"
    assert inner.calls == 3
    assert waits == [0.5, 1.0]


def test_a_failure_that_will_not_go_away_is_not_retried() -> None:
    inner = FlakyClient([LlmError("wrong key")])
    waits: list[float] = []
    with pytest.raises(LlmError):
        make(inner, waits).complete("hi")
    assert inner.calls == 1
    assert waits == []


def test_it_gives_up_after_the_attempts() -> None:
    inner = FlakyClient([RetryableLlmError("busy")] * 3)
    waits: list[float] = []
    with pytest.raises(RetryableLlmError):
        make(inner, waits).complete("hi")
    assert inner.calls == 3
    assert len(waits) == 2


def test_the_server_can_say_how_long_to_wait() -> None:
    inner = FlakyClient([RetryableLlmError("slow down", retry_after=3.0)])
    waits: list[float] = []
    make(inner, waits).complete("hi")
    assert waits == [3.0]


def test_the_wait_has_a_ceiling() -> None:
    inner = FlakyClient([RetryableLlmError("busy")] * 5)
    waits: list[float] = []
    make(inner, waits, max_attempts=6).complete("hi")
    assert waits == [0.5, 1.0, 2.0, 4.0, 8.0]


def test_a_stream_is_retried_only_before_the_first_piece() -> None:
    inner = FlakyClient([RetryableLlmError("busy")], reply="one two")
    waits: list[float] = []
    assert list(make(inner, waits).stream("hi")) == ["one", "two"]
    assert inner.calls == 2


def test_a_stream_that_breaks_after_a_piece_is_not_retried() -> None:
    class Breaks:
        calls = 0

        def complete(self, prompt: str) -> str:
            return ""

        def stream(self, prompt: str) -> Iterator[str]:
            self.calls += 1
            yield "one"
            raise RetryableLlmError("lost connection")

    inner = Breaks()
    waits: list[float] = []
    pieces: list[str] = []
    with pytest.raises(RetryableLlmError):
        for piece in RetryingClient(inner, sleep=waits.append).stream("hi"):
            pieces.append(piece)
    assert pieces == ["one"]
    assert inner.calls == 1


def make_real(status: int, headers: dict[str, str] | None = None) -> AnthropicClient:
    def handler(request: httpx2.Request) -> httpx2.Response:
        return httpx2.Response(status, headers=headers or {}, json={"type": "error", "error": {"type": "x", "message": "x"}})

    return AnthropicClient(api_key="test-key", http_client=httpx2.Client(transport=httpx2.MockTransport(handler)))


@pytest.mark.parametrize("status", [429, 500, 503, 529])
def test_these_statuses_can_be_retried(status: int) -> None:
    with pytest.raises(RetryableLlmError):
        make_real(status).complete("hi")


@pytest.mark.parametrize("status", [400, 401, 403, 404])
def test_these_statuses_are_not_retried(status: int) -> None:
    with pytest.raises(LlmError) as info:
        make_real(status).complete("hi")
    assert not isinstance(info.value, RetryableLlmError)


def test_retry_after_is_read_from_the_header() -> None:
    with pytest.raises(RetryableLlmError) as info:
        make_real(429, {"retry-after": "7"}).complete("hi")
    assert info.value.retry_after == 7.0

In deps.py, wrap the real client, and keep the fake one as it is:

import os
from typing import Annotated

from fastapi import Depends

from my_ai_project.llm import AnthropicClient, FakeLlmClient, StreamingClient
from my_ai_project.retry import RetryingClient
from my_ai_project.services import SummaryService
from my_ai_project.summarizer import LlmClient


def get_llm_client() -> StreamingClient:
    if os.environ.get("LLM_MODE", "fake") == "real":
        api_key = os.environ.get("ANTHROPIC_API_KEY")
        if not api_key:
            raise RuntimeError("LLM_MODE is real, but ANTHROPIC_API_KEY is not set")
        return RetryingClient(AnthropicClient(api_key=api_key, timeout=30.0), max_attempts=3)
    return FakeLlmClient()


LlmDep = Annotated[StreamingClient, Depends(get_llm_client)]


def get_summary_service(client: LlmDep) -> SummaryService:
    return SummaryService(client)


SummaryDep = Annotated[SummaryService, Depends(get_summary_service)]

7 · Check yourself 5 min

  1. Why is the SDK’s default timeout of 600 seconds a problem for a chat, and what do you do about it?
  2. Why does backoff use a random part (jitter)?
  3. Which of these do you retry: 429, 401, a timeout, 400, 529? Why?
Answers
  1. A stuck call could hold the user for ten minutes. You set a shorter timeout (for example 30 seconds) in the client and treat the timeout as an error you handle.
  2. If every client waits exactly the same time, they all come back at the same instant and overload the provider again. A random part spreads the retries out.
  3. Retry 429, a timeout and 529: they may go away. Do not retry 401 (wrong key) or 400 (bad request): they will fail the same way every time.
