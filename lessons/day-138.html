2 · The contract 5 min

Today there is no code to copy. You write the reliability module yourself, from a blank file, with its tests. You get a contract.

reliability.py
  Unavailable(Exception)                         raised when every way of getting an answer failed
  with_timeout(call, seconds) -> str             waits at most `seconds`; raises TimeoutError; the slow call is simply ignored
  FallbackWriter(primary, secondary|None, timeout, names)
      complete(prompt, system) tries the primary under the timeout;
      on LlmError or TimeoutError it tries the secondary (if there is one), under the timeout;
      on a failure of both, or of the only one, it raises Unavailable (with a clear message);
      any OTHER exception (a bug) is not caught;
      `used` is names[0] or names[1]: which model answered
  cache_key(role, question, top_k) -> str        normalised question + ROLE + top_k
  AnswerCache(ttl_seconds, max_entries, clock)   get(key) / put(key, value) / clear(); entries expire; it cannot grow without limit;
                                                 `clock` can be replaced, so that a test can move time

API (wired in app code):
  /api/ask looks in the cache before the pipeline; a hit costs no tokens and the metrics say model = 'cache'
  an Unavailable becomes 503 {"detail": "the assistant is temporarily unavailable"}
  the metrics say which model answered (the 'used' of the writer)

Predict first, before you write anything: which tests will you write? Think of the case where two requests look the same but must not share an answer, and the case where the cache must stop serving an old answer.

Hint: where to start

A dataclass Entry(value, expires_at) and a dictionary. get returns None and removes the key when the entry is missing or expires_at <= clock(). put removes the oldest key (next(iter(dict))) when the cache is full. For the key, a normalised question: re.sub(r"\s+", " ", q.strip().lower()).

import concurrent.futures
import logging
import re
import time
from collections.abc import Callable
from dataclasses import dataclass

from my_ai_project.grounding import Writer
from my_ai_project.llm import LlmError

logger = logging.getLogger("reliability")


class Unavailable(Exception):
    """Every way of getting an answer failed. The caller shows a clear message; it does not crash."""


def with_timeout(call: Callable[[], str], seconds: float) -> str:
    """Give up waiting after some seconds. The slow call keeps running in its thread (Python cannot kill a thread): the answer is simply ignored."""
    pool = concurrent.futures.ThreadPoolExecutor(max_workers=1)
    future = pool.submit(call)
    try:
        return future.result(timeout=seconds)
    except concurrent.futures.TimeoutError as err:
        raise TimeoutError(f"no answer after {seconds} seconds") from err
    finally:
        pool.shutdown(wait=False)


class FallbackWriter:
    """Try the first model; if it fails or is too slow, try the second. `used` says which one answered, for the metrics."""

    def __init__(self, primary: Writer, secondary: Writer | None, timeout: float = 20.0, names: tuple[str, str] = ("primary", "fallback")) -> None:
        self.primary, self.secondary, self.timeout, self.names = primary, secondary, timeout, names
        self.used = names[0]

    def complete(self, prompt: str, system: str | None = None) -> str:
        try:
            return with_timeout(lambda: self.primary.complete(prompt, system), self.timeout)
        except (LlmError, TimeoutError) as err:
            logger.warning("the first model failed (%s: %s)", type(err).__name__, err)
            if self.secondary is None:
                raise Unavailable("the model did not answer and there is no fallback") from err
        secondary = self.secondary
        try:
            self.used = self.names[1]
            return with_timeout(lambda: secondary.complete(prompt, system), self.timeout)
        except (LlmError, TimeoutError) as err:
            logger.error("the fallback model failed too (%s: %s)", type(err).__name__, err)
            raise Unavailable("neither model answered") from err


def normalize(question: str) -> str:
    return re.sub(r"\s+", " ", question.strip().lower())


def cache_key(role: str, question: str, top_k: int) -> str:
    """The role is part of the key: an answer made for staff must never be served to a customer."""
    return f"{role}|{top_k}|{normalize(question)}"


@dataclass
class Entry:
    value: object
    expires_at: float


class AnswerCache:
    """A small in-memory cache with a time to live. It trades freshness for speed and cost, so its limit is written down: an answer can be this old."""

    def __init__(self, ttl_seconds: float = 300.0, max_entries: int = 500, clock: Callable[[], float] = time.monotonic) -> None:
        self.ttl, self.max_entries, self.clock = ttl_seconds, max_entries, clock
        self.entries: dict[str, Entry] = {}
        self.hits = 0
        self.misses = 0

    def get(self, key: str) -> object | None:
        entry = self.entries.get(key)
        if entry is None or entry.expires_at <= self.clock():
            self.entries.pop(key, None)
            self.misses += 1
            return None
        self.hits += 1
        return entry.value

    def put(self, key: str, value: object) -> None:
        if len(self.entries) >= self.max_entries:
            self.entries.pop(next(iter(self.entries)))   # the oldest one goes
        self.entries[key] = Entry(value, self.clock() + self.ttl)

    def clear(self) -> None:
        self.entries.clear()

import time

import pytest

from my_ai_project.llm import LlmError, RetryableLlmError
from my_ai_project.reliability import AnswerCache, FallbackWriter, Unavailable, cache_key, with_timeout


class Says:
    def __init__(self, text: str) -> None:
        self.text, self.calls = text, 0

    def complete(self, prompt: str, system: str | None = None) -> str:
        self.calls += 1
        return self.text


class Fails:
    def __init__(self, error: Exception) -> None:
        self.error, self.calls = error, 0

    def complete(self, prompt: str, system: str | None = None) -> str:
        self.calls += 1
        raise self.error


class Slow:
    def __init__(self, seconds: float) -> None:
        self.seconds = seconds

    def complete(self, prompt: str, system: str | None = None) -> str:
        time.sleep(self.seconds)
        return "too late"


def test_the_first_model_answers_when_it_can() -> None:
    primary, backup = Says("from the first"), Says("from the second")
    writer = FallbackWriter(primary, backup)
    assert writer.complete("q") == "from the first" and writer.used == "primary" and backup.calls == 0


@pytest.mark.parametrize("error", [LlmError("down"), RetryableLlmError("busy")])
def test_a_failing_first_model_falls_back_to_the_second(error: Exception) -> None:
    writer = FallbackWriter(Fails(error), Says("from the second"))
    assert writer.complete("q") == "from the second" and writer.used == "fallback"


def test_a_slow_first_model_is_given_up_on() -> None:
    writer = FallbackWriter(Slow(1.0), Says("from the second"), timeout=0.1)
    started = time.perf_counter()
    assert writer.complete("q") == "from the second"
    assert time.perf_counter() - started < 0.8   # it did not wait for the slow one


def test_when_everything_fails_the_error_is_clear() -> None:
    with pytest.raises(Unavailable, match="neither model answered"):
        FallbackWriter(Fails(LlmError("a")), Fails(LlmError("b"))).complete("q")
    with pytest.raises(Unavailable, match="no fallback"):
        FallbackWriter(Fails(LlmError("a")), None).complete("q")


def test_a_bug_is_not_hidden_by_the_fallback() -> None:
    with pytest.raises(ValueError):
        FallbackWriter(Fails(ValueError("a bug")), Says("x")).complete("q")


def test_with_timeout_returns_a_quick_answer() -> None:
    assert with_timeout(lambda: "ok", 1.0) == "ok"


def test_the_role_is_part_of_the_cache_key() -> None:
    assert cache_key("staff", "What does E104 mean?", 3) != cache_key("customer", "What does E104 mean?", 3)
    assert cache_key("staff", "  What  does E104 MEAN? ", 3) == cache_key("staff", "what does e104 mean?", 3)
    assert cache_key("staff", "x", 3) != cache_key("staff", "x", 5)


def test_an_entry_expires_after_its_time_to_live() -> None:
    now = [0.0]
    cache = AnswerCache(ttl_seconds=10, clock=lambda: now[0])
    cache.put("k", "v")
    assert cache.get("k") == "v"
    now[0] = 11.0
    assert cache.get("k") is None and (cache.hits, cache.misses) == (1, 1)


def test_the_cache_does_not_grow_without_limit() -> None:
    cache = AnswerCache(max_entries=2)
    for key in ("a", "b", "c"):
        cache.put(key, key)
    assert cache.get("a") is None and cache.get("c") == "c"

Read the result

The most important test is the one for the key: an answer cached for staff must not be served to a customer. It is also the one that is easiest to forget, because everything else works without it. Run the API twice with the same question and look at the metrics:

You should see
model     rows   avg latency   tokens in
cache     3      1.4 ms        0           <- the same question asked again by the same role: no model, no cost
stand-in  21     11.4 ms       3573

(From the 24 requests of the dashboard run: three questions were repeated.) A cache hit took about 1.4 ms against 11.4 ms on average, and cost no tokens. And the limit, to write in your README: an answer can be as old as the time to live (here 300 seconds); after a change to the pages, restart the service or clear the cache. A conftest fixture that resets the cache between tests is also needed: without it, an answer cached by one test leaks into the next (this was a real failure while writing this lesson).

4 · Check yourself 5 min

  1. Why is the role part of the cache key?
  2. What limit must you write down for a cache?
  3. Why reset the cache between tests?
Answers
  1. So that an answer made for staff (with staff-only sources) is never served to a customer.
  2. How old an answer can be: the time to live, and the fact that a change to the pages is not seen until it expires or the cache is cleared.
  3. A cache in the application state lives as long as the process, so an answer cached by one test would be served in the next and hide bugs.
