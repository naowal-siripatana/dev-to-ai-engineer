2 · The goal 5 min

Your capstone has two services: the Python service that knows about AI, and an ASP.NET Core layer that will own the rest of the application (users, business rules, the front door). Today you build the smallest useful version of the second one. By the end:

  • A new project AskGateway with POST /api/ask that forwards the question to /api/ask of the Python service and returns its answer with the sources.
  • The request is checked in .NET first (a bad request is a 400 and never reaches Python).
  • Failures of the other service become clear statuses: 502 when it is down, 503 when its database is down, 504 when it is too slow.
  • The address and the timeout come from configuration.
  • Tests that start the gateway with a stub instead of Python.
  • The checkpoint: curl through .NET returns an answer.
Capstone: this is the first piece of the ASP.NET Core layer. Later it gets login, the user’s role, logging and the other business endpoints. Keep it small and clear today.
About the answers. The Python service answers with its simulated writer here (see Day 77), so the wording is not a real model’s. The gateway does not care: it forwards whatever the service returns. The lesson was built and run with the .NET 10 SDK; AddValidation() is new in .NET 10, so on .NET 8 or 9 you check the request by hand.

Step 2: models and JSON

The C# records use PascalCase (TopK), the Python service uses snake_case (top_k). One set of options converts both ways. The attributes on AskRequest are the checks for the request:

using System.ComponentModel.DataAnnotations;

namespace AskGateway;

// The shapes of the Python service (POST /api/ask). The JSON names are snake_case there (top_k, doc_id),
// and PascalCase here: the naming policy in ApiJson converts between them.
public record AskRequest(
    [property: Required, StringLength(500, MinimumLength = 1)] string Question,
    [property: Range(1, 10)] int TopK = 3);

public record Source(string Citation, string DocId, int ChunkIndex, string Title, string Kind, string Text, double Similarity);

public record AskResponse(string Question, string Answer, bool Refused, string Reason, List<Source> Sources);
using System.Text.Json;

namespace AskGateway;

public static class ApiJson
{
    // One set of options for everything that talks JSON: snake_case, like the Python service.
    public static readonly JsonSerializerOptions Options = new(JsonSerializerDefaults.Web)
    {
        PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower,
    };
}

Step 3: the client

A typed HttpClient. It turns every way the other service can fail into an exception with the right status for your callers:

using System.Net;

namespace AskGateway;

public class PythonServiceException(int statusCode, string message) : Exception(message)
{
    public int StatusCode { get; } = statusCode;
}

public class PythonServiceClient(HttpClient http, ILogger<PythonServiceClient> logger)
{
    public async Task<AskResponse> AskAsync(AskRequest request, CancellationToken cancellationToken)
    {
        HttpResponseMessage response;
        try
        {
            response = await http.PostAsJsonAsync("/api/ask", request, ApiJson.Options, cancellationToken);
        }
        catch (HttpRequestException error)
        {
            logger.LogWarning("python service is not reachable: {Message}", error.Message);
            throw new PythonServiceException(StatusCodes.Status502BadGateway, "the AI service is not reachable");
        }
        catch (TaskCanceledException) when (!cancellationToken.IsCancellationRequested)
        {
            logger.LogWarning("python service timed out");
            throw new PythonServiceException(StatusCodes.Status504GatewayTimeout, "the AI service took too long");
        }

        using (response)
        {
            if (response.StatusCode == HttpStatusCode.ServiceUnavailable)
            {
                throw new PythonServiceException(StatusCodes.Status503ServiceUnavailable, "the AI service cannot reach its database");
            }
            if (!response.IsSuccessStatusCode)
            {
                logger.LogWarning("python service answered {Status}", (int)response.StatusCode);
                throw new PythonServiceException(StatusCodes.Status502BadGateway, $"the AI service answered with status {(int)response.StatusCode}");
            }
            var answer = await response.Content.ReadFromJsonAsync<AskResponse>(ApiJson.Options, cancellationToken);
            return answer ?? throw new PythonServiceException(StatusCodes.Status502BadGateway, "the AI service sent an empty answer");
        }
    }
}

Step 4: the endpoint and configuration

Program.cs sets up the client from configuration, turns on request validation, and maps the endpoint. A client error from your validation is a 400; a PythonServiceException becomes a problem response with its status:

using AskGateway;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddValidation();                       // checks [Required], [StringLength], [Range] on the request
builder.Services.ConfigureHttpJsonOptions(o => o.SerializerOptions.PropertyNamingPolicy = ApiJson.Options.PropertyNamingPolicy);
builder.Services.AddHttpClient<PythonServiceClient>(client =>
{
    var settings = builder.Configuration.GetSection("PythonService");
    client.BaseAddress = new Uri(settings["BaseUrl"] ?? "http://localhost:8000");
    client.Timeout = TimeSpan.FromSeconds(settings.GetValue("TimeoutSeconds", 30));
});

var app = builder.Build();

app.MapGet("/health", () => Results.Ok(new { status = "ok" }));

app.MapPost("/api/ask", async (AskRequest request, PythonServiceClient python, CancellationToken cancellationToken) =>
{
    try
    {
        return Results.Ok(await python.AskAsync(request, cancellationToken));
    }
    catch (PythonServiceException error)
    {
        return Results.Problem(detail: error.Message, statusCode: error.StatusCode);
    }
});

app.Run();

public partial class Program;   // lets a test project start the app

appsettings.json (an environment variable such as PythonService__BaseUrl overrides it):

Step 5: tests

The tests start the whole gateway in memory and replace the HTTP handler of the Python client with a stub. They need no Python, no database and no model:

using System.Net;
using System.Net.Http.Json;
using Microsoft.AspNetCore.Mvc.Testing;
using Microsoft.AspNetCore.TestHost;
using Microsoft.Extensions.DependencyInjection;

namespace AskGateway.Tests;

// A stand-in for the Python service: the tests need no Python, no database and no model.
class StubHandler(Func<HttpRequestMessage, HttpResponseMessage> reply) : HttpMessageHandler
{
    public HttpRequestMessage? LastRequest { get; private set; }
    public string? LastBody { get; private set; }

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        LastRequest = request;
        LastBody = request.Content is null ? null : await request.Content.ReadAsStringAsync(cancellationToken);
        return reply(request);
    }
}

public class GatewayTests
{
    const string PythonAnswer = """
        {"question":"How often?","answer":"Once a month [manual-calibration#0].","refused":false,"reason":"",
         "sources":[{"citation":"[manual-calibration#0]","doc_id":"manual-calibration","chunk_index":0,"title":"Calibration guide","kind":"manual","text":"Calibrate once a month.","similarity":0.85}]}
        """;

    static HttpClient ClientWith(StubHandler handler) =>
        new WebApplicationFactory<Program>()
            .WithWebHostBuilder(host => host.ConfigureTestServices(services =>
                services.AddHttpClient<PythonServiceClient>().ConfigurePrimaryHttpMessageHandler(() => handler)))
            .CreateClient();

    static HttpResponseMessage Json(HttpStatusCode status, string body) =>
        new(status) { Content = new StringContent(body, System.Text.Encoding.UTF8, "application/json") };

    [Fact]
    public async Task A_question_is_forwarded_and_the_answer_comes_back_with_its_sources()
    {
        var python = new StubHandler(_ => Json(HttpStatusCode.OK, PythonAnswer));
        var response = await ClientWith(python).PostAsJsonAsync("/api/ask", new { question = "How often?", top_k = 2 });

        Assert.Equal(HttpStatusCode.OK, response.StatusCode);
        Assert.Equal("/api/ask", python.LastRequest!.RequestUri!.AbsolutePath);
        Assert.Contains("\"top_k\":2", python.LastBody);                  // snake_case towards Python
        var body = await response.Content.ReadAsStringAsync();
        Assert.Contains("\"doc_id\":\"manual-calibration\"", body);       // and snake_case back to the caller
        Assert.Contains("\"refused\":false", body);
    }

    [Theory]
    [InlineData("", 3)]
    [InlineData("x", 0)]
    [InlineData("x", 11)]
    public async Task A_bad_request_is_a_400_and_never_reaches_python(string question, int topK)
    {
        var python = new StubHandler(_ => Json(HttpStatusCode.OK, PythonAnswer));
        var response = await ClientWith(python).PostAsJsonAsync("/api/ask", new { question, top_k = topK });

        Assert.Equal(HttpStatusCode.BadRequest, response.StatusCode);
        Assert.Null(python.LastRequest);
    }

    [Fact]
    public async Task A_python_503_stays_a_503()
    {
        var python = new StubHandler(_ => Json(HttpStatusCode.ServiceUnavailable, """{"detail":"the database is not available"}"""));
        var response = await ClientWith(python).PostAsJsonAsync("/api/ask", new { question = "x" });
        Assert.Equal(HttpStatusCode.ServiceUnavailable, response.StatusCode);
    }

    [Fact]
    public async Task A_python_service_that_is_down_is_a_502()
    {
        var python = new StubHandler(_ => throw new HttpRequestException("connection refused"));
        var response = await ClientWith(python).PostAsJsonAsync("/api/ask", new { question = "x" });
        Assert.Equal(HttpStatusCode.BadGateway, response.StatusCode);
    }

    [Fact]
    public async Task An_unexpected_python_status_is_a_502()
    {
        var python = new StubHandler(_ => Json(HttpStatusCode.InternalServerError, "{}"));
        var response = await ClientWith(python).PostAsJsonAsync("/api/ask", new { question = "x" });
        Assert.Equal(HttpStatusCode.BadGateway, response.StatusCode);
    }
}

6 · Stuck? anytime

  • A 502 although Python is running: check the port in PythonService:BaseUrl. Python must listen on 8000 (--port 8000).
  • Every request is a 400 “Question field is required”: the JSON field is question (the naming policy is snake_case), and the body needs content-type: application/json.
  • AddValidation does not exist: you are on .NET 8 or 9. Check the two values by hand and return Results.ValidationProblem(...).
  • Tests fail with “Program is inaccessible”: the last line of Program.cs must be public partial class Program;.
  • The first call is slow: the Python service loads its model once.
  • Git shows hundreds of files: add bin/ and obj/ to .gitignore before the first commit.

8 · Check yourself 5 min

  1. Why does the gateway check the request itself when Python checks it too?
  2. Which status for: Python is down; Python’s database is down; Python is too slow?
  3. Why is the address of the Python service in configuration?
Answers
  1. A bad request is stopped at the front door and costs nothing, and the gateway must not depend on another service’s rules to protect itself.
  2. 502 Bad Gateway; 503 Service Unavailable; 504 Gateway Timeout.
  3. The address changes between your laptop, a test and a server. Configuration changes it without a rebuild, and a test can point at a stub.
