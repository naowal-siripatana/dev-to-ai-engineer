DAY 159 · LEVEL 13: MODEL SERVING · MIXED PRACTICE

Mixed practice: switch the provider to a local model by configuration

40 minhands-onfree
Today you will be able to switch your assistant between a stand-in and a local model by configuration only, from a blank file.

1 · Warm-up 3 min

Answer from memory, then open the answers.

  1. What three things change when you move from one OpenAI-compatible server to another?
  2. Why is the first call to a model server slow?
Answers
  1. The address, the model name, and sometimes the key.
  2. The server loads the model into memory on the first call. Warm it up.

2 · Today 2 min

Today you practise without the lesson open. Goal: the same API answers through the stand-in or through a model on your own machine, chosen by environment variables only, and the metrics say who answered. You write the pieces from a blank file, then compare with the model below.

Be clear about what was run. Everything below ran for real on one laptop: the project’s own API, once with the stand-in writer and once with a 1.5 billion model (4-bit) behind mlx_lm.server. No hosted model and no key was used. Ollama and vLLM were not run.

3 · Plan first 5 min

On paper: which setting says who answers? Which settings does a local provider need that the hosted one does not (and which does it not need)? Where in the code should the choice be made, so that the rest of it never asks “which provider?” Then open the sketch.

The plan

One new setting for the provider, one for the address, and the model name (it differs between servers). The hosted provider needs a key; the local one needs an address and a name, and a key only if the server asks. The choice is made in one function that returns the client; every caller just receives a writer.

4 · Do it from a blank file 25 min

On the branch local-model. Write each piece before you open the model. Run pytest and mypy after each one.

  1. The settings. Add a provider (two allowed values), an address and the model. Add the rules to from_env: a wrong provider, a missing address, a missing model name, each with a message that names the setting.
  2. One function that picks the client. It takes the settings and a model name and returns the client, wrapped in the retry. Use it in get_writer.
  3. Tests with no server. A fake transport answers the HTTP call. Check: the request has the system prompt, the model name and a temperature of 0; a busy server (503) is a retryable error and a bad request (400) is not; a server that is down is retryable; the provider is chosen by configuration only; the config errors.
  4. Run it for real. Start your server, then your API twice (two terminals, two ports): once with LLM_MODE=fake and once with the four local variables. Ask the same question and a question that should be refused.
  5. Look at the metrics. Query the requests table for the model column and the cost column. Is the number in the cost column correct for a model on your laptop?

Break it on purpose: start the API with LLM_PROVIDER=openai_compatible and no address, then with LLM_PROVIDER=ollama. Read each message.

Piece 1: the settings
from collections.abc import Mapping
import os
from typing import Literal

from pydantic import BaseModel, ConfigDict, SecretStr


class ConfigError(Exception):
    """A setting is missing or wrong. The message says which one and what to do."""


class Settings(BaseModel):
    model_config = ConfigDict(frozen=True)

    llm_mode: Literal["fake", "real"] = "fake"
    anthropic_api_key: SecretStr | None = None   # SecretStr: printing it shows ********
    llm_provider: Literal["anthropic", "openai_compatible"] = "anthropic"   # who answers when LLM_MODE is real
    llm_base_url: str | None = None   # only for openai_compatible: the address of the server, for example http://localhost:8081/v1
    llm_model: str = "claude-haiku-4-5-20251001"
    llm_fallback_model: str | None = None
    database_url: SecretStr = SecretStr("postgresql://assistant:assistant@localhost:5433/assistant")   # has a password in it
    audit_log: str = "logs/audit.jsonl"
    price_input_per_million: float | None = None   # US dollars; None = use the default for the provider
    price_output_per_million: float | None = None

    @classmethod
    def from_env(cls, environ: Mapping[str, str] | None = None) -> "Settings":
        env = os.environ if environ is None else environ
        mode = env.get("LLM_MODE", "fake")
        if mode not in ("fake", "real"):
            raise ConfigError(f"LLM_MODE is {mode!r}: use 'fake' or 'real'")
        provider = env.get("LLM_PROVIDER", "anthropic")
        if provider not in ("anthropic", "openai_compatible"):
            raise ConfigError(f"LLM_PROVIDER is {provider!r}: use 'anthropic' or 'openai_compatible'")
        key = env.get("ANTHROPIC_API_KEY") or None   # an empty string counts as not set
        if mode == "real" and provider == "anthropic" and key is None:
            raise ConfigError("LLM_MODE is real, but ANTHROPIC_API_KEY is not set")
        if mode == "real" and provider == "openai_compatible" and not env.get("LLM_BASE_URL"):
            raise ConfigError("LLM_PROVIDER is openai_compatible, but LLM_BASE_URL is not set")
        if mode == "real" and provider == "openai_compatible" and not env.get("LLM_MODEL"):
            raise ConfigError("LLM_PROVIDER is openai_compatible, but LLM_MODEL is not set (the name differs between servers)")
        values: dict[str, object] = {"llm_mode": mode, "llm_provider": provider, "anthropic_api_key": key}
        for field, name in (("llm_base_url", "LLM_BASE_URL"), ("llm_model", "LLM_MODEL"), ("llm_fallback_model", "LLM_FALLBACK_MODEL"), ("database_url", "DATABASE_URL"), ("audit_log", "AUDIT_LOG"), ("price_input_per_million", "LLM_PRICE_INPUT"), ("price_output_per_million", "LLM_PRICE_OUTPUT")):
            if env.get(name):
                values[field] = env[name]
        return cls(**values)   # type: ignore[arg-type]

    def prices(self) -> dict[str, float]:
        """Dollars per million tokens for the cost column. A model on your own machine has no per-token fee, so it is 0 by default
        (that is NOT the same as free: hardware and electricity cost something). Set LLM_PRICE_INPUT and LLM_PRICE_OUTPUT to override."""
        if self.price_input_per_million is not None and self.price_output_per_million is not None:
            return {"input": self.price_input_per_million, "output": self.price_output_per_million}
        if self.llm_provider == "openai_compatible":
            return {"input": 0.0, "output": 0.0}
        return {"input": 1.00, "output": 5.00}   # the EXAMPLE prices of Day 130: put the real ones of your model here

    def api_key(self) -> str:
        """The only place where the secret leaves its wrapper."""
        if self.anthropic_api_key is None:
            raise ConfigError("ANTHROPIC_API_KEY is not set")
        return self.anthropic_api_key.get_secret_value()
Piece 2: one function picks the client
def make_client(settings: Settings, model: str) -> StreamingClient:
    """The one place that decides who answers: the settings choose the provider, the rest of the code does not know."""
    if settings.llm_provider == "openai_compatible":
        assert settings.llm_base_url is not None   # from_env has checked it
        key = settings.anthropic_api_key.get_secret_value() if settings.anthropic_api_key else "not-needed"
        return RetryingClient(OpenAICompatibleClient(base_url=settings.llm_base_url, model=model, api_key=key, timeout=60.0), max_attempts=2)
    return RetryingClient(AnthropicClient(api_key=settings.api_key(), model=model, timeout=30.0), max_attempts=2)

Piece 3: the tests
import json
from typing import Any

import httpx2
import pytest

from my_ai_project.deps import make_client, get_writer
from my_ai_project.llm import LlmError, RetryableLlmError
from my_ai_project.local_llm import OpenAICompatibleClient
from my_ai_project.reliability import FallbackWriter
from my_ai_project.settings import ConfigError, Settings


def make(handler: Any) -> OpenAICompatibleClient:
    return OpenAICompatibleClient("http://local.test/v1", "tiny-model", http_client=httpx2.Client(transport=httpx2.MockTransport(handler)))


def reply(text: str) -> dict[str, Any]:
    return {
        "id": "x", "object": "chat.completion", "created": 1, "model": "tiny-model",
        "choices": [{"index": 0, "finish_reason": "stop", "message": {"role": "assistant", "content": text}}],
        "usage": {"prompt_tokens": 12, "completion_tokens": 5, "total_tokens": 17},
    }


def test_the_request_has_the_system_prompt_the_model_name_and_temperature_zero() -> None:
    seen: dict[str, Any] = {}

    def handler(request: httpx2.Request) -> httpx2.Response:
        seen["url"] = str(request.url)
        seen["body"] = json.loads(request.content)
        return httpx2.Response(200, json=reply("E101 means a sensor timeout."))

    assert make(handler).complete("What is E101?", "Be brief.") == "E101 means a sensor timeout."
    assert seen["url"] == "http://local.test/v1/chat/completions"
    assert seen["body"]["model"] == "tiny-model"
    assert seen["body"]["temperature"] == 0
    assert seen["body"]["messages"] == [{"role": "system", "content": "Be brief."}, {"role": "user", "content": "What is E101?"}]


def test_a_busy_server_is_a_retryable_error_and_a_bad_request_is_not() -> None:
    with pytest.raises(RetryableLlmError):
        make(lambda request: httpx2.Response(503, json={"error": {"message": "busy"}})).complete("hi")
    with pytest.raises(LlmError) as err:
        make(lambda request: httpx2.Response(400, json={"error": {"message": "bad"}})).complete("hi")
    assert not isinstance(err.value, RetryableLlmError)


def test_a_server_that_is_not_running_is_a_retryable_error() -> None:
    def handler(request: httpx2.Request) -> httpx2.Response:
        raise httpx2.ConnectError("connection refused")

    with pytest.raises(RetryableLlmError):
        make(handler).complete("hi")


def test_the_provider_is_chosen_by_configuration_only() -> None:
    local = Settings.from_env({"LLM_MODE": "real", "LLM_PROVIDER": "openai_compatible", "LLM_BASE_URL": "http://localhost:8081/v1", "LLM_MODEL": "tiny"})
    assert type(make_client(local, "tiny").inner).__name__ == "OpenAICompatibleClient"   # type: ignore[attr-defined]
    hosted = Settings.from_env({"LLM_MODE": "real", "ANTHROPIC_API_KEY": "not-a-real-key"})
    assert type(make_client(hosted, "m").inner).__name__ == "AnthropicClient"   # type: ignore[attr-defined]


def test_the_local_provider_needs_an_address_and_a_model_name_but_no_key() -> None:
    with pytest.raises(ConfigError, match="LLM_BASE_URL is not set"):
        Settings.from_env({"LLM_MODE": "real", "LLM_PROVIDER": "openai_compatible", "LLM_MODEL": "tiny"})
    with pytest.raises(ConfigError, match="LLM_MODEL is not set"):
        Settings.from_env({"LLM_MODE": "real", "LLM_PROVIDER": "openai_compatible", "LLM_BASE_URL": "http://x/v1"})
    with pytest.raises(ConfigError, match="LLM_PROVIDER is 'ollama'"):
        Settings.from_env({"LLM_PROVIDER": "ollama"})
    Settings.from_env({"LLM_MODE": "real", "LLM_PROVIDER": "openai_compatible", "LLM_BASE_URL": "http://x/v1", "LLM_MODEL": "tiny"})


def test_get_writer_builds_a_fallback_writer_for_the_local_provider(monkeypatch: pytest.MonkeyPatch) -> None:
    for name, value in {"LLM_MODE": "real", "LLM_PROVIDER": "openai_compatible", "LLM_BASE_URL": "http://localhost:8081/v1", "LLM_MODEL": "tiny"}.items():
        monkeypatch.setenv(name, value)
    assert isinstance(get_writer(), FallbackWriter)


def test_a_local_model_has_no_per_token_price_unless_you_set_one() -> None:
    assert Settings.from_env({}).prices() == {"input": 1.0, "output": 5.0}   # the examples of Day 130
    local = {"LLM_MODE": "real", "LLM_PROVIDER": "openai_compatible", "LLM_BASE_URL": "http://x/v1", "LLM_MODEL": "tiny"}
    assert Settings.from_env(local).prices() == {"input": 0.0, "output": 0.0}
    assert Settings.from_env({**local, "LLM_PRICE_INPUT": "0.2", "LLM_PRICE_OUTPUT": "0.4"}).prices() == {"input": 0.2, "output": 0.4}

The fix is a price list that comes from the settings, with 0 as the default for a local provider. (0 means no fee per token. 6 · Check yourself 5 min

  1. Where is the choice of provider made, and why only there?
  2. Why does the API refuse to start with LLM_PROVIDER=ollama?
  3. What did the cost column show for the local model before the fix, and why was it wrong?
Answers
  1. In one function (make_client) that takes the settings. The rest of the code receives a writer and never asks which provider it is, so adding a third provider changes one place.
  2. The value is not one of the allowed ones; failing at start with the name of the setting is better than failing later inside a request.
  3. A small amount of money, computed with the example price list of an API. A model on your own machine has no per-token price, so the number was invented by the default.
