Mixed practice: cite or refuse

40 minhands-onfree
Today you will be able to answer five questions with citations and refuse when there is no source, from a blank file.

1 · Warm-up 3 min

Answer from memory, then open the answers.

  1. Why do you fuse two searches by rank and not by adding the scores?
  2. What is an invented citation?
Answers
  1. The scores are in different units: a keyword score is much bigger than a similarity, so one list would decide. Ranks can be compared.
  2. A citation in the answer that is not one of the chunks you gave to the model.

Hint: where to start

Loop over the questions. For each: retrieve(question, embedder, store, top_k=3). If nothing came back or the best similarity is under MIN_SCORE, print the NO_ANSWER sentence from prompts.py and continue. Otherwise ground(question, found, SimulatedWriter()) and print answer.text.

Solution
import os

from my_ai_project.embedder import FastEmbedder
from my_ai_project.grounding import ground
from my_ai_project.pipeline import retrieve
from my_ai_project.prompts import NO_ANSWER
from my_ai_project.simulated import SimulatedWriter
from my_ai_project.store import ChunkStore

MIN_SCORE = 0.6
QUESTIONS = [
    "How often should I calibrate the sensor?",
    "How do I silence the alarm?",
    "What does error E104 mean?",
    "Where can I buy a coffee?",
    "What is the capital of France?",
]

store = ChunkStore(os.environ.get("DATABASE_URL", "postgresql://assistant:assistant@localhost:5433/assistant"))
embedder = FastEmbedder()
writer = SimulatedWriter()

for question in QUESTIONS:
    found = retrieve(question, embedder, store, top_k=3)
    if not found or found[0].similarity < MIN_SCORE:
        best = found[0].similarity if found else 0.0
        print(f"{question}\n  {NO_ANSWER}  (best similarity {best:.2f})")
        continue
    answer = ground(question, found, writer)
    print(f"{question}\n  {answer.text}  (best similarity {found[0].similarity:.2f})")

Read the E104 line, then fix it

The best similarity for the E104 question is 0.73, higher than for the alarm question, and the answer is still “not found”. The score says something similar exists (other error pages), not the answer exists. The E104 page was never retrieved (Day 72 and Day 74). Swap in the hybrid search:

from my_ai_project.hybrid import KeywordIndex, hybrid_search

keywords = KeywordIndex(store.all_chunks())
...
found = hybrid_search(question, embedder, store, keywords, top_k=3)
best = max((f.similarity for f in found), default=0.0)   # not found[0]: after fusion the first chunk may have 0.0
You should see
What does error E104 mean?
  The storage is above 95 percent [error-e104#0].

Now it is answered, with the right citation. Notice the comment: after fusion, the first chunk may come from the keyword list only and have a similarity of 0.0, so take the best similarity of the whole list.

4 · Check yourself 5 min

  1. Why do you check the best similarity before calling the writer?
  2. Why can a high similarity still end in “not found”?
  3. What does the answer line give a reader that a plain answer does not?
Answers
  1. If nothing is close, the sources cannot help, and a writer might fill the gap with something made up. Refusing in code does not depend on the writer’s mood, and it saves a model call.
  2. The score measures how close the best chunk is, not whether the answer is in it. The right page may not have been retrieved at all.
  3. A citation: the reader can open the page and check the answer, and your code can check that the page was really retrieved.
