Core Concepts

The ideas worth actually understanding

Docker Compose

One command (docker compose up) brings up React, ASP.NET Core, Python FastAPI, and PostgreSQL together — the single most important 'does this look like a real system' signal for a reviewer.

Quantization

Shrinking a model's weights (FP16 → INT8/INT4) to trade a little quality for much lower VRAM/cost — relevant if you ever explore running a model locally instead of via API.

Model serving (Ollama/vLLM)

Running an LLM as a local, OpenAI-compatible API endpoint — useful to know even if your capstone stays cloud-API-based, since 'when would I go local' is a real interview question.

CI/CD & health checks

Automating build/test/deploy and exposing a status endpoint — standard practice you already follow, now applied to a system with an AI service in the mix.

From .NET To This

Bridging from what you already know

If you already do Docker and CI/CD-adjacent work, the new material is squarely in local model serving/GPU territory (quantization, VRAM, vLLM). This series skips fine-tuning and Kubernetes, so treat the local-serving content as valuable context, not a mandate to swap cloud API calls for a self-hosted model.
Hands-On Checkpoint

What "done" looks like for this module

Write a docker-compose.yml that brings up all four services (React, ASP.NET Core, Python AI, PostgreSQL) with one command, plus a GitHub Actions workflow that runs your tests and builds the images on push.

Watch Out

Pitfalls & anti-patterns

  • Don't chase local model serving (Ollama/vLLM) as a scope addition this late — it's good context, not a March deliverable.
  • Don't leave secrets (API keys) in the repo or the Docker image — use environment/secret management properly.
Key Takeaways

Before you move on

  • `docker compose up` working end-to-end is worth more to a reviewer than any single feature.
  • Local model serving is worth understanding conceptually; don't let it become new scope this late in the plan.
  • This module closes the infrastructure story — March is about polish and applying, not new tech.
