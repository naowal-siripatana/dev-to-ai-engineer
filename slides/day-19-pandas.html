Pandas Data Processing

DataFrames for tabular data
Goal: load, filter, group and clean a small table in a few lines.
Core

DataFrame basics

import pandas as pd

df = pd.read_csv("error_codes.csv")   # columns: code, system, severity, text
df.head()
df[df["severity"] == "high"]          # filter rows
df.groupby("system")["code"].count()  # count per system
A DataFrame is a table; each column is a Series.
Cleaning

The usual three moves

df = df.drop_duplicates(subset="code")
df["text"] = df["text"].fillna("").str.strip()
df = df.rename(columns={"text": "description"})
From Another Language

Bridge

DataFrame

Like a DataTable, but built for column-wise operations.

Filter

Like LINQ Where.

groupby

Like LINQ GroupBy plus an aggregate.

merge

Like a SQL JOIN.

Watch Out

Pitfalls

  • Do not loop over rows with for; use column operations.
  • Many operations return a new DataFrame; assign the result.
  • Loading a huge file fully into memory can fail; read in chunks.
Hands-On

~45 minutes

  • Build error_codes.csv with about 20 rows.
  • Filter by severity, count per system, drop duplicates.
  • Save the cleaned result to a new CSV.
