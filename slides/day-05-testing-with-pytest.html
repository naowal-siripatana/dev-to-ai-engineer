Testing with pytest

Test AI code without calling the AI
Goal today: write a pytest test that checks an AI function without calling the real model.
Hook

Tests that call the real AI

Slow

Seconds for every test run.

Costs money

Every call is billed.

Changes every time

Same question, different words: a test cannot say pass or fail.

The fix

Hand the function a fake that returns a fixed answer.

Piece 1

A test is a small function that checks one thing

def test_returns_the_reply() -> None:
    client = FakeClient("  A short summary.  ")
    assert summarize("Some long text", client) == "A short summary."
pytest runs every test_... function in files named test_....py. assert says what must be true.
Piece 2

Hand the helper in, so a test can swap it

def summarize(text: str, client: LlmClient, max_words: int = 20) -> str:
    ...
    reply = client.complete(f"Summarize in one sentence: {text}")

class FakeClient:
    def __init__(self, reply: str) -> None:
        self.reply = reply
    def complete(self, prompt: str) -> str:
        return self.reply
Real code passes the real client. A test passes a fake. This habit is called dependency injection: "hand it in".
Piece 3

Test the failure too, and watch for silence

def test_empty_text_raises() -> None:
    with pytest.raises(ValueError):
        summarize("   ", FakeClient("x"))
  • A good set: a normal case, an edge case (empty text), and an error case.
  • If the file is not named test_...py, or the function does not start with test_, pytest says no tests ran. Silence is not success.
From Another Language

Bridge

test_ function

Like [Fact] (xUnit) or [Test] (NUnit).

assert

Like Assert.Equal.

pytest.raises

Like Assert.Throws.

FakeClient

Does the job of Moq or NSubstitute. A Protocol is like an interface, but a class fits just by having the method.

Hands-On

~30 minutes in the repo

  • uv add --dev pytest, then copy the files and run uv run pytest -q (4 passed)
  • Change max_words to 4 in a test, predict the failure, read it
  • Comment out the empty-text check and read DID NOT RAISE
  • Your turn: summarize_or_default with a fake that raises TimeoutError (6 passed), then play the Test Detective game and commit
Capstone Tie-In

Where this goes

Every test in the project runs with no network and no API key, so CI can run them for free. Real model calls are checked later, with evaluation.
