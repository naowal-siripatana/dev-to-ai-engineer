Core Concepts

The ideas worth actually understanding

AGENTS.md / CLAUDE.md

A file that tells a coding agent your project's conventions, commands, and constraints — the same role an onboarding doc plays for a new hire, but read by the AI on every session.

Verification-driven development

Give the agent a way to check its own work (tests, a build, a lint pass) instead of trusting its claim that something works.

AI code slop

Plausible-looking but low-quality or subtly wrong code an agent produces when under-supervised — the antidote is the same code review discipline you'd apply to a junior engineer's PR.

Context rot (for code)

A long agent session accumulates irrelevant history that degrades its output quality — sometimes the fix is a fresh session, not a longer prompt.

Watch Out

Pitfalls & anti-patterns

  • Don't merge agent-written code you haven't actually read — that's how code slop gets into a portfolio project.
  • Don't let an agent session run unbounded; check in and course-correct rather than hoping it self-corrects.
Key Takeaways

Before you move on

  • An AGENTS.md/CLAUDE.md file is cheap and pays off across every future session.
  • Verification (tests, builds) is what makes agent output trustworthy, not the agent's own confidence.
  • This is a time-budget multiplier for the rest of the project — use it deliberately.
