async/await & Pydantic Models

Waiting efficiently, and validating at runtime
Goal today: run 3 fake LLM calls concurrently, and validate a ChatRequest with Pydantic.
async

Why async? Because LLM calls mostly wait

  • async def defines a coroutine that can pause at await.
  • While one call waits on the network, the event loop runs other work on the same thread.
  • asyncio.run(main()) starts the event loop.
async

gather: 3 calls in ~1s, not 3s

async def fake_llm_call(prompt: str) -> str:
    await asyncio.sleep(1)
    return f"answer to: {prompt}"

results = await asyncio.gather(
    fake_llm_call("a"), fake_llm_call("b"), fake_llm_call("c")
)
Watch Out

async pitfalls

  • No await gives a coroutine object, not a result ("never awaited").
  • time.sleep or a sync HTTP client inside async def blocks the whole loop.
  • async helps with waiting (I/O), not CPU-heavy work.

async / await

Event loop

Usually one thread, no thread pool. A blocking call stalls everything.
