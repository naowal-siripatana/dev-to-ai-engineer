ML Fundamentals

How models learn from data
Goal: a working vocabulary for the rest of the bootcamp.
Core Idea

Types of learning

Supervised

Learn from labeled examples: input and the right answer.

Unsupervised

Find structure with no labels, such as clustering.

Self-supervised

Labels come from the data itself. This is how LLMs are pretrained.

Reinforcement

Learn from reward signals.

Vocabulary

Terms to know

  • Features: the inputs. Label: the answer you want.
  • Training: adjusting parameters to fit data. Inference: using the trained model.
  • Loss: how wrong the model is. Training lowers it.
  • Parameters: the numbers learned. A model is mostly its parameters.
Watch Out

Overfitting

  • A model that memorizes training data fails on new data.
  • Training accuracy alone tells you nothing; measure on held-out data.
  • This is why the next topic is train, validation and test splits.
From Another Language

Bridge

Traditional code is rules in, answers out. Machine learning is answers in, rules out: you give examples and the model learns the function. It is a function you did not write, so you test it with data, not with reading it.
Hands-On

  • Write 5 sentences in your own words: supervised vs unsupervised, training vs inference.

Where this goes
