Day 0 · Setup

Get your tools ready

About 30 minutes. Everything is free.
Do this once, before Day 1. If you already have a tool, skip it and tick it on the site.
The goal

By the end you will have

  • A GitHub account, where your code lives
  • Git, which saves the history of your work
  • Visual Studio Code (or an editor you like), where you write code
  • uv, which installs and manages Python for you
  • A work folder open in your editor, with a terminal inside it
Step 1-2

GitHub account and Git

  • Create a free account: github.com/signup
  • Install Git: git-scm.com/downloads. On a Mac, running git --version in the Terminal may offer to install it for you.
  • Open a terminal and run:
git --version
It should print a version number, like git version 2.x.
Step 3

Editor and terminal

  • Install Visual Studio Code: code.visualstudio.com
  • The terminal is a text window where you type commands. Mac: the Terminal app. Windows: PowerShell. In VS Code: menu Terminal, then New Terminal.
  • Make a folder for your work and open it in VS Code (File, Open Folder).
Keep the terminal inside your work folder. Most commands in this series are run there.
Step 4

uv and Python

  • Follow the official guide: docs.astral.sh/uv (it can change, so copy from there). Typical commands:
# Mac / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Close and reopen the terminal after installing, so it finds uv.
Check it works

Four commands, four answers

git --version
uv --version
uv python install 3.12
uv run --python 3.12 python --version
Each command should print a version (the last one should show Python 3.12). If one fails, go to the next slide.
If something fails

Common problems

command not found

Close and reopen the terminal. Then try again. If it still fails, the tool is not installed yet.

Windows: scripts blocked

Use PowerShell, and use the Windows command from the guide.

Wrong folder

Run pwd (Mac) or cd (Windows) to see where you are, and open the right folder.
