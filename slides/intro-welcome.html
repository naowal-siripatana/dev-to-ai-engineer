How this bootcamp is designed

Hard lessons, made easy to reach

Less theory, more trying. Every day has things you actually do: type it, run it, break it, fix it.

The quest

13 levels in 4 stages

1. Build the backend

Python, FastAPI, a service that talks to an AI model (levels 1-2).

2. Understand the model

Tokens, embeddings, LLM apps, prompting (levels 3-5).

3. Make it smart and measurable

RAG, tools, agents, evaluation (levels 6-8).

4. Make it production-ready

AI-assisted engineering, design, security, operations, deployment (levels 9-13).

Setup · Day 0

Get your tools ready (about 30 minutes, all free)

1. GitHub account

Where your code lives. github.com/signup

2. Git

Saves the history of your work. git-scm.com/downloads

3. Visual Studio Code

Or the editor you like best. code.visualstudio.com

4. uv

Installs and manages Python for you. uv install guide

Each step is also on the site, with a checkbox: Day 0 never locks anything.
Setup · check it works

Four commands, four answers

git --version
uv --version
uv python install 3.12
uv run --python 3.12 python --version
If a command prints a version number, that tool is ready. If not, it isn't installed yet (or your terminal needs to be reopened). Tick the step on the site when it works.
