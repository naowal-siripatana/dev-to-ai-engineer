Module 02 · Day 15

Project Lab: Three Endpoints

Saturday, about 3 hours
Checkpoint: POST /api/chat, /api/summarize and /api/extract, validated, logged, tested, pushed to GitHub.
Plan

How to spend the 3 hours

  • 30 min: define request and response Pydantic models for all three endpoints.
  • 60 min: implement them behind an LLMClient interface, with a fake implementation first.
  • 45 min: tests with the fake LLM.
  • 30 min: swap in a real LLM call for one endpoint.
  • 15 min: README and push.
Design

One interface, two implementations

class LLMClient(Protocol):
    async def complete(self, prompt: str) -> str: ...

class FakeLLM:
    async def complete(self, prompt: str) -> str:
        return "stub"

class RealLLM:
    async def complete(self, prompt: str) -> str:
        ...  # call the provider SDK here
Endpoints

Contracts to write first

/api/chat

question in, answer out.

/api/summarize

text in, summary out, optional max length.

/api/extract

text in, a typed object out (for example error code and cause).

Errors

Return a consistent error shape, not raw tracebacks.

Watch Out

Pitfalls

  • Do not put the API key in code or in git. Use an environment variable.
  • Do not build RAG yet. Plain pass-through to the LLM is the goal.
  • Stop at a working, tested version; polish later.
Done Means

Definition of done

  • Three endpoints return validated JSON.
  • At least one test per endpoint passes with the fake LLM.
  • Every call is logged with latency.
  • README explains how to run it.
  • Pushed to GitHub.
Capstone Tie-In

Where this goes

This is the first working version of the AI Service. Every later module adds to these same endpoints.
