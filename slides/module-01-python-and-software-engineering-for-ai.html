Core Concepts

The ideas worth actually understanding

Type hints & Pydantic

Python's answer to the strong typing you already rely on in C# — catch shape errors before runtime, not after.

async / await

Same concept as C#'s async/await: don't block a thread while waiting on I/O (an LLM call, a DB query).

Project structure

src-layout, pyproject.toml, uv for dependency locking — the Python equivalent of a .csproj/.sln setup.

Testing & logging

pytest instead of xUnit; structlog/logging instead of ILogger. Same discipline, different syntax.

From .NET To This

Bridging from what you already know

You already write typed, tested, logged production code in C#. This module is mostly a syntax and tooling translation, not a new discipline. The one real gap: Python's duck typing and dynamic nature means type hints are a convention, not a compiler guarantee — Pydantic is what gives you back the runtime safety net C# gives you for free.
