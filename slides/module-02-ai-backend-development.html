Core Concepts

The ideas worth actually understanding

FastAPI

The ASP.NET Core Web API of Python — routes, DI, automatic OpenAPI docs, request validation via Pydantic.

Dependency injection

Same pattern as .NET's built-in DI container, just wired with Depends() instead of a service collection.

Background tasks

FastAPI's BackgroundTasks / a task queue plays the role of a .NET hosted service or Azure Function for fire-and-forget work.

API security

API keys, auth headers, rate limiting on the routes that call an LLM — the same threat model as any public API, plus cost risk.

From .NET To This

Bridging from what you already know

FastAPI will feel closer to ASP.NET Core than almost anything else in this bootcamp: routing, DI, model binding, and auto-generated docs are all direct analogues. Lean on that similarity to move fast here and bank the extra time for the genuinely new material later (Modules 3, 6, 7).

Watch Out

Pitfalls & anti-patterns

  • Don't call the LLM directly from a route handler with no timeout/retry — a hung call takes your API down with it.
  • Don't skip request validation "since it's just a demo" — bad input plus an LLM call is where cost surprises come from.
