COURSE OUTLINE

Dev to AI Engineer
in 6 months

A free, hands-on learn-along for developers. One real project, 13 levels, one small win a day. Built in public by Naowal, a learning designer who is learning with you.

176 days13 levels1 real projectabout 10 h a week2 videos a weekfree
By the end you will have built and deployed an AI knowledge assistant, and you will be able to explain how every part of it works.

Who it is for

This is for you if

  • You can write code in any language (C#, Java, JavaScript, Python...).
  • You want to build AI features, not just use chat tools.
  • You can give about 10 hours a week, and you like to learn by doing.
  • You want a project you can show, not a pile of exercises.

You do not need

  • A maths or machine learning background.
  • Python experience (we start from zero in Python).
  • A GPU, or any paid tool to start. Day 0 is free.
  • To finish in exactly 6 months. The plan waits for you.

What you will be able to do

  1. Write clean, typed, tested Python and set up a project the way a professional does.
  2. Build a FastAPI service that calls an LLM, with validation and logging.
  3. Explain tokens, context windows and embeddings in plain words.
  4. Build RAG on PostgreSQL with pgvector, with answers that cite their sources.
  5. Give an assistant tools (function calling and MCP) and a simple agent loop.
  6. Measure quality with a golden question set instead of feelings.
  7. Spot prompt injection and add guardrails and audit logs.
  8. Operate and deploy it: tracing, a cost dashboard, Docker Compose and CI.

The one project

You do not build 13 small demos. You build one project, ai-knowledge-assistant: a tool that answers questions about a private knowledge base (manuals, FAQs, error codes) and cites its sources. It grows a little every Saturday.

How a lesson works

  • Warm-up: two questions from earlier days, from memory.
  • Hook and the idea: at most 3 small ideas, each with an example.
  • Worked example: a finished example with its real output.
  • Try it: 4 steps, from copy-and-run to your own version. One step breaks the code on purpose.
  • Stuck? Check yourself: hints, then the solution; 3 questions to answer in your own words.
  • Tick the checklist: the next Day unlocks.

Built on retrieval practice, spaced review, worked examples and learning by doing.

Questions

Can I join late?

Yes. Sign in and your plan is counted from the day you sign in. Start with Day 0, then Day 1. You can watch the videos in any order, but the checklists work best in order.

Do I need an AI or maths background?

No. You need to be able to write code in any language. We start with Python from the first lesson.

Is it really free?

Yes. The lessons, slides, checklists and videos are free. Some labs call an LLM API that may cost a little. Each lab says what it needs.

What if I fall behind?

Nothing breaks. The next Day unlocks when you finish the checklist, not when the date arrives. Every Sunday has a catch-up slot, and a missed day never moves the next week.

Do I need to know C# or .NET?

No. The project has an ASP.NET Core layer in front of the Python AI service, and that layer is optional. You can follow every level with the Python service alone.

Will I get a certificate or a job?

No certificate and no promise of a job. You get one real project you can run, explain and show, and a public record of your work.

Who is teaching?

Nobody is a teacher here. Naowal is a learning designer and software developer who is doing the same journey in public, one day ahead of you, mistakes included.
